# 학생앱 151차수 검토 — 공지 = "학생에게 보이기"를 켠 수업 기록만 (2026-11-04)

원장 요청(11-04): 📌 고정만 눌러도 선생님끼리 보는 메모("영어 80점 이상", "천일문 기본 단어들을 어려워함")가 학생 공지로 떴다. 근본 해결 = 원장앱에 "학생에게 보이기" 스위치를 따로 두고, 학생앱은 그것만 본다.

## 1. 학생에게 보이는 공지 기준이 바뀜
- 전에는: 수업 기록 중 📌 고정을 누른 글이 학생 공지(더보기 → 공지·설문, 홈 공지 수, 앱 켤 때 "새 공지" 카드)로 떴어요.
- 지금은: 수업 기록 중 **👀 학생에게 보이기**를 켠 글만 떠요. 📌 고정은 원장앱 안에서만 쓰는 표시가 됐어요. 고정했어도 "보이기"를 안 켰으면 학생에게 안 보여요. 반대로 고정 없이 "보이기"만 켜도 학생에게 보여요.
- 확인법: 원장앱 15단계가 올라간 뒤, 수업 기록에서 👀를 켠 글만 학생 공지에 나와요. 그 전(지금)에는 학생 공지가 비어 "새 공지가 없어요"로 보여요 — 새는 쪽보다 안 보이는 쪽이 안전해서 그렇게 했어요.
