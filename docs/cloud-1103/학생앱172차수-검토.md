# 학생앱 172차수 검토 — 단어 기록 지키기 (2026-11-12)

단어장(`public/voca.html`)이 서버와 기록을 맞추는 방법을 **"덮어쓰기"에서 "합치기"로** 바꿨습니다. 고친 것은 4개입니다.

## 고친 것

### 1. 다른 기기에서 공부한 기록이 지워지던 것
- 전에는: 저장할 때마다 이 기기의 기록 전체를 서버에 그대로 올렸습니다. 폰에 단어 탭을 켜 둔 채 태블릿에서 공부하고, 다시 폰에서 한 단어만 풀면 폰의 옛 기록이 태블릿 공부를 지웠습니다.
- 이제는: 올리기 전에 서버 기록을 먼저 봅니다(앱을 켠 뒤 처음, 화면에 돌아왔을 때, 1분에 한 번). 그 사이 다른 기기가 저장했으면 **두 기록을 합친 뒤** 올립니다.
- 합치는 규칙: 회독·왕관·맞힌 횟수는 큰 쪽, 쓴 뜻·회독 통과 표시는 양쪽 모두 살림. 별표·제외 표시는 이 기기 것. 공부한 것은 사라지지 않습니다.

### 2. 새 폰·새 브라우저에서 빈 기록이 서버를 지우던 것
- 전에는: 서버 기록을 받기 전에(또는 못 받은 채) 책을 열면 빈 기록에 "방금" 시각이 찍혀 서버를 덮어썼습니다.
- 이제는: **서버 기록을 못 봤으면 올리지 않습니다.** 폰에는 남아 있고, 다음에 서버가 보이면 합쳐서 올립니다. 빈 기록과 합치면 서버 기록이 그대로 남습니다.

### 3. 숙제 TEST를 끝낸 직후 앱을 닫으면 도장이 사라지던 것
- 전에는: 보내기에 "실패한 뒤에만" 폰에 적어 뒀습니다. 보내는 도중 탭을 바꾸거나 앱을 닫으면 다시 보낼 것이 안 남았습니다.
- 이제는: **보내기 전에 먼저 폰에 적어 두고**, 성공하면 지웁니다. 화면을 닫아도 보내던 것은 끝까지 보내게 했습니다(keepalive).

### 4. 링크 오류 때 폰에 남은 공부까지 지우던 것
- 전에는: 서버가 403/404로 답하면(열쇠 빠진 링크, 재발급 직후 등) 폰의 단어 기록을 무조건 지웠습니다.
- 이제는: 서버에 아직 못 올린 공부가 폰에 있으면 지우지 않습니다.

### 같이 고친 작은 것
- 화면을 떠나는 순간(탭 바꾸기·앱 닫기) 마지막 0.25초의 답이 폰에 안 적히던 것 → 떠날 때 바로 적습니다.
- 책 초기화: 초기화한 시각을 적어 둬서, 다른 기기의 옛 기록과 합쳐져도 지운 기록이 되살아나지 않습니다.
- 기기 시계가 틀려도(시각을 "크다/작다"로 비교하지 않고 "내가 아는 것과 같은가"로 비교) 결과가 달라지지 않습니다.

## 고친 파일
- `public/voca.html` — `store`(writeLocal·flushNow), `mergeWord`·`mergeLayer`·`mergeRoot`·`reconcileWith`, `pushServer`, 켤 때 맞추기, `fullReset`, `checkWithdrawnAndBlock`, `finishHw`, `sendHwRecord`
- `src/core/config.jsx` — 버전 글씨 172차수

## 확인한 것 (가짜 서버를 붙여 브라우저로 직접 돌림)
| 경우 | 결과 |
|---|---|
| 켜 둔 폰 + 다른 기기가 그 사이 공부 | 올린 기록에 양쪽 단어가 모두 있음(w1,w2,w3 + 폰의 w9), 회독은 큰 쪽(2), 다른 책도 살아 있음 |
| 새 폰 + 서버 기록 받기 실패 | 올리기 0번. 서버가 다시 되자 서버 기록과 합쳐 1번 올림(서버 단어 그대로) |
| 새 폰 + 정상 | 서버 기록을 받기만 하고 올리기 0번 |
| 이 기기에서 책 초기화 + 서버에 옛 기록 | 초기화 상태 그대로 올라감(단어 0개), 왕관은 큰 쪽 |
| 고치기 전부터 쓰던 폰(처음 한 번) | 폰 단어와 서버 단어가 모두 살아서 올라감 |
| 숙제 도장 보내는 도중 | 폰에 도장 메모가 있음 → 성공하면 지워짐 |

- 빌드 성공. 화면 오류 없음.

## 아직 못 본 것
- **진짜 책 자료로 실제 퀴즈를 풀면서는 못 봤습니다.** 기록을 직접 넣고 저장을 시켜서 확인했습니다.
- 진짜 워커와 붙여 본 것이 아닙니다. 워커가 기록이 없는 학생에게 무엇을 돌려주는지에 따라 첫 저장이 달라질 수 있어, 배포 뒤 학생 한 명으로 확인이 필요합니다.
- 두 기기를 정말 동시에(1분 안에 번갈아) 쓰는 경우는, 그 1분 사이 것은 나중에 저장한 쪽이 이깁니다. 다음에 화면에 돌아오면 다시 합쳐지지만, 이미 덮인 것은 못 살립니다.

## 알아 두실 것
- 서버 요청이 조금 늘어납니다: 올리기 전에 "서버 기록 보기"가 1분에 한 번쯤 더 붙습니다.
- 맞힘/틀림 표시가 두 기기에서 서로 다르면 "맞힘" 쪽으로 합칩니다(학생에게 유리한 쪽).
- **워커에 부탁하면 더 안전해지는 것**(지금 안 해도 됩니다): 올릴 때 "내가 본 서버 시각"을 같이 보내고, 다르면 워커가 거절해 주는 것. 그러면 위 "1분 사이" 틈도 막힙니다. 필요하시면 워커 채팅에 전할 글을 써 드리겠습니다.

## 쉬운 요약
단어 기록을 서버에 올릴 때 이제 덮어쓰지 않고 합칩니다. 다른 기기 공부, 새 폰, 숙제 도장이 사라지던 길을 막았습니다. 아직 배포는 안 했습니다.
