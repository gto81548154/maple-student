# 학생앱 166차수 검토 — 달력 색 다시 짜기 · 결석만 표시

그림: 166차수-달력.png (왼쪽 = 펼친 달력, 가운데 = 접은 달력, 오른쪽 = 지난 날짜를 누른 모습)

## 1. 달력 색을 다섯 가지로 다시 나눴어요
전에는: 방학과 시험이 둘 다 노란색, 휴원과 결석이 둘 다 빨간색이라 헷갈렸어요.
지금은: 등원일 = 파랑, 보강·변경 = 보라, 시험 = 노랑, 휴원·방학 = 회색, 결석 = 빨강. 서로 겹치는 색이 없어요.
확인법: 학생 화면 홈 → 달력 아래 색 설명 줄을 봐요. 다섯 가지만 있어요.

## 2. 칸 안 글자는 전부 두 글자예요
전에는: "시험기간"처럼 긴 글자였고, 보강은 작은 보라 점이었어요.
지금은: 보강, 변경, 시험, 휴원, 결석 — 전부 두 글자로 칸 안에 적혀요. 내 학년 영어 시험 날만 "영어시험"이라고 나와요.
확인법: 보강이 있는 날, 시험 기간, 쉬는 날 칸을 봐요.

## 3. 방학과 휴원을 하나로 합쳤어요
전에는: 방학 기간은 노란 칸, 휴원은 빨간 칸으로 따로였어요.
지금은: 둘 다 회색이에요. 방학 중에 학원에 오는 날은 그냥 등원일(파랑)로 보여요.
확인법: 방학 시간표가 있는 학생의 방학 기간을 봐요. 오는 날은 파랑, 안 오는 날은 회색이에요.

## 4. 칸에는 결석만 표시해요
전에는: 칸에 출석(✓), 지각(△), 결석이 다 그려졌어요.
지금은: 칸에는 결석만 나와요. 출석 ✓와 지각 △는 뺐어요.
확인법: 지난 날짜 칸을 봐요. ✓와 △가 없어요. 결석한 날만 빨간 칸에 "결석"이라고 나와요.

## 5. 날짜를 누르면 지각·출석 기록은 그대로 보여요
전에는: 날짜를 누르면 그날 기록이 나왔어요.
지금은: 똑같아요. 지각한 날을 누르면 "몇 분 지각"과 도착 시간이 그대로 보여요.
확인법: 지각했던 날짜를 눌러 봐요.

## 6. 남은 수업 목록에 "시험" 표시가 다시 들어갔어요
전에는: 두 줄로 바꾸면서 "시험기간" 표시를 뺐어요.
지금은: 시험 기간에 있는 수업 줄에 "시험" 표시가 붙어요. 표시 색도 달력 칸과 같은 색이에요(보강·변경 = 보라, 시험 = 노랑).
확인법: 시험 기간 안에 수업이 있는 학생의 목록을 봐요.

정한 것
- 한 줄에 표시가 두 개 붙거나("보강"+"시험") 글자가 길면("영어시험") 표시를 날짜 아랫줄로 내렸어요. 좁은 칸에서 겹치지 않게 하려고요.
- 한 날에 여러 가지가 겹치면 칸 색은 이 순서로 정해요: 결석 → 휴원 → 시험 → 보강·변경 → 등원일. 그래서 시험 기간 안의 수업 날은 칸이 노란색("시험")으로 보이고, 수업이 있다는 것은 아래 목록에서 알 수 있어요. (이 순서는 전과 같아요.)
- 방학 중 안 오는 날은 회색 칸이지만 글자는 안 적었어요. 날마다 "방학"이라고 적히면 지저분해서요. "휴원" 글자는 학원이 쉬는 날에만 나와요.
- 날짜를 눌렀을 때 나오는 이름표 색도 맞췄어요(휴원 = 회색, 시험 = 진한 노랑).
