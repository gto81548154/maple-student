# 12단계 — 원장앱(academy-mgmt) 녹음 듣기 + 장학금·친구 소개 확인·지급 (원장앱 299·300차수)

이 문서는 **원장앱(academy-mgmt) 저장소**에서 쓰는 지시문이다. 원장앱 저장소의 `docs/cloud-1103/0-공통규칙.md`를 먼저 읽는다(없으면 이 문서 맨 아래 "공통 규칙"). 워커 길은 11단계 지시문(워커)대로 만들어진다고 보고, 워커가 아직 안 올라갔으면 404·연결 실패를 "아직 준비 중" 안내로 조용히 처리한다(원장앱이 멈추면 안 된다).

학생앱 쪽은 끝나 있다: 학생은 더보기 → 녹음 제출(145차수)에서 녹음을 보내고, 더보기 → 장학금·친구 소개(146차수)에서 신청한다. 학생 화면에는 선생님이 "들었음"을 찍으면 **"선생님 확인 ✓"**, 메모를 적으면 그 아래 한 줄, 장학금은 상태(신청함/확인 중/지급 완료/지급 안 됨+이유)가 보인다.

## 미리 알아둘 것
- 워커 주소·원장 열쇠는 원장앱이 이미 쓰는 값(기존 `/admin/...` 호출을 찾아 같은 방식으로). 부르는 방식도 기존 함수(타임아웃 붙은 fetch + JSON)를 재사용한다.
- 소리·사진 파일 주소: `${워커}/files/<key>?mk=<원장 열쇠>` (워커 11단계 A-3). `<audio src>`·`<img src>`에 바로 넣는다.
- 화면 글은 원장·선생님용 한국어. 기존 원장앱 스타일(색·단추·표)을 그대로 따른다.

## A. 녹음 듣기 — 원장앱 299차수
9단계 지시문으로 이미 만들었으면 아래와 다른 점만 맞춘다.

1. **PDF 수업실**에 "🎤 녹음" 패널(또는 탭)을 단다. 학생을 고르면 그 학생의 녹음 목록(워커 `GET /admin/recordings?studentId=`)이 날짜별로 묶여 최신 먼저 나온다. 줄마다: 시각, 길이(0:23), 읽은 내용(없으면 흐리게 "읽은 내용 없음"), 들었음 표시.
2. 줄의 [▶]를 누르면 그 자리에서 재생(한 번에 하나만, 다른 줄 누르면 먼저 것 멈춤). 재생이 **끝까지 가면 자동으로 "들었음"** 을 워커에 보낸다(`POST /admin/recording/heard` `{ id, heard:true }`). 수동으로 [들었음 ✓] 토글도 둔다(끄기도 됨).
3. 줄마다 **메모 한 줄**(200자) 입력칸 + [저장]. 저장하면 같은 길로 `{ id, heard:<지금 값>, memo }`. 저장 뒤 "저장했어요" 짧게.
4. 읽은 내용이 있으면 옆에 **[🔊 원어민 듣기]** 단추: 브라우저 `speechSynthesis`로 영어(en-US, 속도 0.9) 읽어 준다(서버 TTS 없음·무료). 안 되는 브라우저면 단추를 숨긴다. 학생 녹음과 번갈아 듣는 용도.
5. 수업실 밖에서도 보이게 **"오늘 들을 녹음"** 목록: 날짜 고르기(기본 오늘) + "안 들은 것만" 체크(워커 `?date=` / `?unheard=1`). 줄에 학생 이름이 함께 나오고 2·3번과 같은 재생·들었음·메모.
6. 원장앱 홈(대시보드) 요약 줄에 "🎤 들을 녹음 n개"(워커 `GET /admin/recordings/count?date=오늘`의 `unheard`). 0이면 줄을 숨긴다. 누르면 5번 화면.

## B. 장학금·친구 소개 확인·지급 — 원장앱 300차수
1. 메뉴에 **"🎁 장학금·소개"** 화면을 단다(학생관리 옆이 자연스럽다). 위에 상태 알약: **기다리는 중(n)** · 확인 중(n) · 지급 완료 · 지급 안 됨 · 전체. 기본은 "기다리는 중". 목록은 워커 `GET /admin/reward-claims?status=`.
2. 줄마다: 신청 날짜, 학생 이름(학교·학년), 종류 배지(성적 장학금 1만원 / 친구 소개 3만원), 내용 한 줄
   - 성적: "2026년 2학기 중간 · 영어 96점 · 시험 11/3" (고등학생은 "중간 1등급 · 기말 1등급")
   - 친구 소개: "김마플 (마플중 중2) · 010-1234-5678"
   - 성적이면 **[성적표 보기]** → 사진을 크게(모달 또는 새 창). 사진 주소는 "미리 알아둘 것" 참고.
   - 상태 배지(기다리는 중 파랑 / 확인 중 주황 / 지급 완료 초록 / 지급 안 됨 빨강) + 이유·메모.
3. 상태 바꾸기 단추(워커 `POST /admin/reward-claim/status`):
   - **[확인 중]** → `status:"checking"`.
   - **[지급 완료]** → 작은 창: 메모(선택, 예 "11/5 카톡으로 보냄") → `status:"paid", reason:<메모>`.
     - 친구 소개면 같은 창에 **"등록한 친구 고르기"**(학생 명단에서 검색해 고름, 선택) → `friendStudentId`를 같이 보낸다. 그러면 워커가 그 친구 앞으로도 3만원 지급 기록을 만든다(학생앱에 둘 다 보인다). 안 고르면 소개한 학생만 지급 처리.
   - **[지급 안 됨]** → 작은 창: 이유(필수, 200자, 예 "성적표 사진이 안 보여요 / 기준 미달") → `status:"rejected", reason`.
   - 바꾼 뒤 목록을 다시 받고 "바꿨어요" 짧게. 실패하면 빨간 안내.
4. 원장앱 홈 요약 줄에 "🎁 확인할 신청 n개"(워커 `GET /admin/reward-claims/count`의 `pending + checking`). 0이면 숨김. 누르면 1번 화면.
5. 규칙 안내(화면 위 접을 수 있는 작은 칸, 원장 확정 11-04): 중학생 학교 중간·기말 영어 95점 이상 → 1만원 기프티콘 / 고등학생 중간·기말 둘 다 영어 1등급 → 1만원 / 친구 소개는 등록하면 둘 다 3만원 / 시험 뒤 한 달 안 신청, 성적표 사진 필수. 기준 판정은 학생앱·워커가 이미 하므로 원장앱은 **보여 주기만** 한다.

## C. 둘 다
- 원장앱 빌드 번호(`APP_BUILD` 같은 장치)를 A는 299차수, B는 300차수로 올린다(한 번에 하면 300차수 하나로).
- 워커 404·연결 실패: 목록 자리에 "워커가 아직 준비 중이에요(11단계)" 한 줄. 단추는 눌러도 같은 안내.

## 확인할 것(검토 md에 적는다)
- 빌드 통과. 메뉴·수업실 패널·홈 요약 줄이 열리는지.
- 가짜 워커(또는 실제 워커)로: 녹음 [▶] 재생 → 끝까지 → 자동 "들었음" → 메모 저장. 장학금 "기다리는 중" → [확인 중] → [지급 완료 + 메모] / [지급 안 됨 + 이유]. 친구 소개 지급 완료 때 친구를 고르면 워커가 친구 쪽 기록을 만드는지(워커가 있으면).
- 워커가 없을 때 조용한 안내.

## 공통 규칙(원장앱 저장소에 0-공통규칙.md가 없을 때)
- 기존 코드 스타일을 그대로 따른다. 지시한 것만 고친다. 줄끝은 그대로.
- 끝낼 때 `npm install` → 빌드 명령 통과.
- 깃: 작업이 끝나면 **main에 바로 커밋하고 올린다**(원장 결정 11-04).
- `docs/cloud-1103/원장앱<차수>차수-검토.md`를 만들어 같이 커밋한다. 쉬운 한국어로, 바뀐 것마다 "전에는 / 지금은 / 확인법" 세 줄씩. 함수 이름·줄 번호·영어 용어는 적지 않는다.
- 막히거나 애매하면 멈추지 말고 가장 자연스러운 쪽으로 정한 뒤, 검토 md 맨 아래 "정한 것"에 한 줄씩 적는다.
