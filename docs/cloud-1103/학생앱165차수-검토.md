# 학생앱 165차수 검토 — 남은 수업 목록을 두 줄로

그림: 165차수-달력.png

## 1. 남은 수업 목록이 두 줄로 나와요
전에는: 남은 수업이 한 줄로 쭉 내려가서 너무 길었어요.
지금은: 왼쪽 줄과 오른쪽 줄, 두 줄로 나눠서 보여요. 왼쪽 줄을 위에서 아래로 읽고, 그다음 오른쪽 줄을 읽으면 돼요. 길이가 반으로 줄었어요.
확인법: 학생 화면 홈 → "다음 수업 안내" 카드의 달력 아래를 봐요.

정한 것
- 화면이 아주 좁은 폰에서는 글자가 겹치지 않게 저절로 한 줄로 나와요.
- 칸이 좁아져서 표시 글자를 줄였어요: "시간변경" → "변경", "방학 시간표" → "방학", "시간 미정" → "미정".
- 목록 줄에 붙던 "시험기간" 표시는 뺐어요. 달력 칸에 이미 노란색으로 보여요.
