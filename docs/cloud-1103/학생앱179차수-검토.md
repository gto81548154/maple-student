# 학생앱 179차수 검토 — 선생님 토익 (2026-11-19)

원장 결정(11-19): 선생님도 토익을 쓴다(복지·자기계발용, 각자 공부). 원장이 선생님 진도를 보는 화면은 만들지 않는다.

## 바꾼 것 (학생앱)
- 토익 탭과 홈의 "6. 토익 LC" · "7. 토익 파트5" 카드: 원장만 → **원장 + 서버가 열어 준 선생님**.
- 서버가 선생님 홈 응답에 `toeic: true`를 내려줄 때만 선생님에게 보인다. 지금 서버(11-12판)는 이 표시가 없으므로 **이 차수를 올려도 선생님 화면은 그대로**다. 앱·서버 어느 쪽을 먼저 올려도 깨지지 않는다.
- 저장 거절 안내 글 "원장 링크를 다시 열어 주세요" → "내 링크를 다시 열어 주세요".
- 파일: `src/screens/teacher/TeacherHome.jsx`, `TeacherHomeTab.jsx`, `src/domain/toeic.jsx`, `toeicSync.mjs`

## 서버(워커)에서 바꿀 것 — 고친 사본을 원장님께 따로 전달(이 저장소에는 넣지 않음: 공개 저장소라 열쇠가 든 파일은 올리지 않는다)
- 토익 기록 문(`/teacher/toeic`): 원장만 → 유효한 선생님 링크 모두. 기록 칸은 사람마다 따로(원장 `toeic3` 그대로, 선생님 `toeic3:{계정id}`).
- 토익 파일(`toeic/`): 선생님 링크로도 열림. 학생 열쇠로는 여전히 안 열림.
- 백업 목록에 `toeic3:` 추가. 선생님 홈 응답에 `toeic: true` 추가.

## 확인한 것
| 경우 | 결과 |
|---|---|
| 새 서버 표시가 있는 선생님 | 토익 탭·홈 카드가 보이고, 기록과 음원을 자기 계정 번호로 요청함 |
| 옛 서버(표시 없음)의 선생님 | 토익 탭 없음, `#toeic` 주소는 홈으로, 토익 요청을 한 번도 안 보냄 |
| 서버 사본(가짜 저장소): 원장 기록 | 선생님이 저장한 뒤에도 그대로 |
| 서버 사본: 선생님 두 명 | 각자 칸에 따로 저장 |
| 서버 사본: 남의 계정 번호 + 내 열쇠, 열쇠 없음 | 403 |
| 서버 사본: 토익 파일 | 선생님 열쇠 열림 · 틀린 열쇠·열쇠 없음 막힘 · 다른 폴더는 전처럼 막힘 |

- 빌드 성공. 서버 사본은 문법 검사만 통과(진짜 DB·R2와 붙여 본 것 아님).

## 같이 찾은 것 — 토익 기록이 서버에 저장되지 않고 있었음
- 받은 워커 파일(11-12판)에는 학생앱 161차수(11-09)부터 토익 화면이 쓰는 저장 방식이 없었다. 원장 화면에서 "저장 기능 업데이트가 필요해요"가 뜨는 것을 원장님 화면 사진으로 확인(11-19). 그동안의 토익 기록은 그 기기에만 남아 있다.
- 그래서 워커 사본의 토익 저장 부분을 새로 썼다(토익 저장 2판):
  - 응답에 저장 방식 판 번호를 실음 → 앱의 "업데이트 필요" 안내가 사라지고 기기에 쌓인 대기 기록이 순서대로 올라간다.
  - 기기마다 저장 번호를 확인 → 응답이 끊겨 다시 보낸 기록을 두 번 쌓지 않는다(파트5 횟수).
  - 두 기기가 동시에 저장해도 한쪽이 조용히 사라지지 않게, 읽은 판 그대로일 때만 쓴다.
  - 답 100개 저장 + 채점. 정답은 R2 `answer-keys/toeic/ets1000.json`(검토 끝난 80회차 묶음)에서 읽는다. **이 파일이 없으면 채점만 거절**되고 나머지는 다 저장된다.

### 추가로 확인한 것 (학생앱의 실제 저장 코드를 새 서버 코드에 붙여 돌림, DB는 가짜)
| 경우 | 결과 |
|---|---|
| 원장의 옛 기록 위에서 시작 | 옛 기록 그대로 보이고 새 기록이 더해짐 |
| 응답이 끊겨 다시 저장 | 파트5 한 번만 세어짐 |
| 기기 두 대 | 양쪽 기록 모두 남음 |
| 저장이 겹침 | 다시 읽고 써서 둘 다 남음 |
| 답 저장 | 저장됨 |
| 정답 자료 없이 채점 | 이유와 함께 거절, [버리기] 뒤 답은 돌려받고 뒤 기록은 저장됨 |
| 정답 자료 있을 때 채점 | 점수·파트별 결과 저장 |
| 검토 뒤 정답이 바뀐 자료 · 보기에 없는 답 | 거절 |
| 선생님 | 자기 칸에만 저장, 원장 칸에 안 섞임 |

- 쓰기 문장(읽은 판 그대로일 때만 쓰기)은 SQLite에서 따로 돌려 확인. 진짜 DB(Turso)·R2와 붙여 본 것은 아니다.

## 아직 못 본 것 / 원장님이 할 일
- 고친 워커를 Cloudflare에 올려야 실제로 바뀐다. 올린 뒤 원장 토익 탭의 보라색 상자가 사라지는지 봐야 한다.
- 채점은 정답 80회차 파일이 R2에 있어야 된다. 그 파일이 어디 있는지는 확인하지 못했다.

## 쉬운 요약
학생앱은 선생님 토익을 받을 준비가 됐고, 서버가 열어 주기 전에는 아무것도 달라지지 않습니다. 토익 기록이 서버에 저장되지 않던 것은 서버 쪽 문제였고, 고친 서버 파일을 원장님께 드렸습니다.
