# 학생앱 189차수 검토 — 수능 2000 책 이름에 "(22개정)", 맨 끝 단원을 "STUDY MORE"로 (2026-11-28)

배경: 워드마스터 수능 2000 단어책에 블랙홀 카드를 넣었다(하이스트·베이직도). 수능 2000의 맨 끝 51번째 단원은 "STUDY MORE"(가장 자주 나오는 숙어·비슷한 말·반대말·헷갈리는 말) 단원인데, 여기에는 블랙홀 카드만 있다. 이 책은 22개정 판이고, 26개정 판은 나중에 새 책으로 따로 넣는다.

## 바꾼 것

### 1. 책 이름
- 전에는: 책장과 단어장 위쪽에 「워드마스터 수능 2000」이라고 나왔다.
- 지금은: 「워드마스터 수능 2000 (22개정)」이라고 나온다. 책 자체(학생 기록이 붙어 있는 책)는 그대로라 회독·왕관·진도는 하나도 안 바뀐다.
- 확인법: 마플보카 책장을 연다 → 수능 2000 카드 이름 끝에 "(22개정)"이 붙어 있다. 책을 열면 맨 위 "마플보카" 옆 작은 글씨도 같다.

### 2. 맨 끝 단원 이름 "STUDY MORE"
- 전에는: 블랙홀을 켜면 맨 끝에 "DAY 51"이 나왔다.
- 지금은: "STUDY MORE"라고 나온다. 단원 목록, 단원을 눌렀을 때 뜨는 방식 고르기 창, 공부 화면 위쪽 줄, 범위를 골랐을 때 시작 단추 등 마플보카에서 이 단원이 나오는 모든 곳에서 똑같이 나온다. (단어 선별 화면에는 원래 표제어 단원만 나오므로 이 단원이 없다.)
- 일반(블랙홀 끔)에서는 이 단원이 아예 안 나온다. 표제어가 없는 단원이라 빈 줄로도 안 보인다.
- 진도·오늘 몫·회독 기록은 전처럼 번호(51)로 저장한다. 이름만 바뀐다.
- 확인법:
  1. 수능 2000 (22개정)을 연다 → DAY 01~DAY 50만 보이고, DAY 01은 "40개 대상"이다.
  2. 블랙홀을 누른다 → 맨 끝에 "STUDY MORE"(288개 대상)가 생기고, DAY 01은 "83개 대상"이다.
  3. STUDY MORE를 누른다 → 방식 고르기 창에 "STUDY MORE · 288단어"라고 나온다.
  4. 범위를 고르는 방식(체크)으로 DAY 49·50·STUDY MORE를 고르면 시작 단추가 "DAY 49–50·STUDY MORE · … 시작"이다.

## 그대로인 것
- 하이스트(DAY 01~50), 베이직(DAY 01~30), 더블보카 Core·Pro(DAY 01~40)는 전과 똑같이 열린다. 하이스트·베이직은 블랙홀도 전처럼 켜진다.
- 학생앱 홈의 숙제 카드 등에 쓰는 짧은 책 이름(워마 수능)은 이번에 안 바꿨다(지시 범위 밖).

## 확인한 것
- 실제 단어책(학원 서버의 수능 2000·하이스트·베이직·더블보카 Core·Pro)을 받아서 마플보카를 폰 크기 화면으로 열어 위 1~4를 확인했다. 학원 서버에는 아무것도 저장하지 않았다(보기 전용 + 가짜 주소).
- 앱 빌드 성공.

## 정한 것
- 범위 시작 단추에서 번호 단원과 STUDY MORE를 같이 고르면 "DAY 49–50·STUDY MORE"처럼 번호 묶음 뒤에 이름을 붙여 적기로 했다(전에는 "DAY 49–51"로 나왔을 자리).

## 검토에서 찾은 것 (이번에 안 고침 — 원장 결정 필요)
1. 학생앱 단어 검색: 숙어(예: carry away)를 검색하면 출처가 "워마 수능 · DAY 51"로 나온다. 단어 검색은 마플보카 밖(학생앱)이라 이번 지시 범위 밖이다. 고치려면 학생앱 단어 검색 이름표에도 STUDY MORE를 넣으면 된다.
2. 책장 단어 수: 아직 시작 안 한 학생의 책장 카드에는 블랙홀 카드까지 센 숫자가 나온다(수능 2000 → 4182단어, 베이직 → 2029단어, 하이스트 → 4948단어). 한 번 열면 표제어 수(수능 2000 → 2000단어)로 바뀐다. 하이스트는 전부터 이랬고, 이번에 블랙홀을 넣은 두 권도 같아졌다. 숫자는 학원 서버(마플싱커)가 세어 주는 값이라 서버 쪽에서 표제어만 세게 바꾸는 게 맞다.
