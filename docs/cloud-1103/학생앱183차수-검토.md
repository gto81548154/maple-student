# 학생앱 183차수 검토 — 출근·퇴근 시각 직접 입력·고치기 (2026-11-19)

원장 요청(11-19): [출근]을 누르면 지금 시각이 찍히는데, 선생님이 시각을 스스로 고르고 고칠 수 있게. 출근·퇴근 둘 다.

## 바꾼 것
- 오늘 출근 칸에 [시간 입력]: 출근·퇴근 시각을 골라 저장한다. 처음 열면 출근 칸에 지금 시각이 들어 있다. [출근]·[퇴근] 단추(지금 시각으로 바로 찍기)도 그대로 있다.
- 기록이 있으면 단추 이름이 [고치기]로 바뀐다 — 시각 고치기, 퇴근 지우기(비워서 저장), [기록 지우기].
- 캘린더에서 **지난 날**을 고르면 그 날 기록과 [고치기] 또는 [기록 넣기]가 나온다. 깜빡한 날을 선생님이 스스로 채울 수 있다.
- 미래 날짜에는 칸이 안 나오고, 아직 오지 않은 시각은 서버가 거절한다.
- 직접 넣은 기록에는 **"직접 입력"** 표시가 붙는다 — 선생님 화면과 원장 캘린더 둘 다. 단추로 찍은 기록에는 안 붙는다. 원장이 고친 기록은 전처럼 "고침".
- 파일: `src/screens/teacher/TeacherCheckin.jsx`, `TeacherCalTab.jsx`
- 서버(워커 사본): `/teacher/checkin`이 `{ date, in, out }`를 받는다(자기 기록만). `checkinV: 3`일 때만 앱이 [시간 입력]을 보인다.

## 알아 둘 것
- 181차수에서는 "시각은 서버 시계로만 찍힌다"가 원칙이었다. 이번 요청으로 선생님이 시각을 고를 수 있게 됐으므로, 기록은 **선생님이 적은 값**이 된다. 대신 손으로 넣은 것은 "직접 입력"으로 표시해 단추로 찍은 것과 구분되게 했다.

## 같이 넣은 것 (워커 사본만)
- 마스터 홈과 원장 링크를 합칠 준비: 원장 문(`/teacher/*`)이 `tid=admin` + 마스터 열쇠도 원장으로 받는다. 선생님 계정 번호로는 이 길을 못 쓴다. 학생앱 쪽은 아직 안 바꿨다(원장님 결정 뒤).

|---|---|

| 서버 사본: 아직 안 온 시각 · 내일 | 거절 |

## 아직 못 본 것
- 진짜 서버와 붙여 본 것이 아니다.
- 실제 폰의 시각 고르는 창(기기마다 모양이 다름)은 보지 못했다.

## 쉬운 요약
선생님이 출근·퇴근 시각을 직접 골라 적고 고칠 수 있습니다. 지난 날도 채울 수 있고, 손으로 넣은 기록은 "직접 입력"으로 표시됩니다.
