# 학생앱 149차수 검토 — 마플 로드맵(1~7단계 내 위치) (2026-11-04)

원장 요청(11-04): 학생이 자기가 어느 수준인지 알게, 원장앱 정규 커리큘럼(1~7단계) 지도를 학생앱에도. 이름은 "마플 로드맵".

## 1. 더보기 "학습 진도"가 "마플 로드맵"으로 바뀜
- 전에는: 더보기 → 학습 묶음에 "📈 학습 진도 — 교재별 진행 상황"(진도 맵이 있는 학생만).
- 지금은: "🗺️ 마플 로드맵 — 지금 5단계 (고1~고2) · 내가 어디까지 왔는지". 홈 아래쪽 바로가기 줄도 같은 이름이에요. 주소(#progress)는 그대로라 예전 링크도 열려요.
- 확인법: 아래 탭 더보기 → 마플 로드맵.

## 2. 위 칸: 나는 지금 몇 단계
- 전에는: 없던 화면이에요.
- 지금은: 남색 칸에 "나는 지금 **5단계** · 고1~고2"가 크게, 아래에 1~7단계 막대(지나온 칸은 연노랑, 지금 칸은 노랑·빛남, 각 칸 아래 "초5~초6"처럼 학년대). 그 아래 "지금 하는 책 · 단어-워드마스터-수능 23/50과" 한 줄. 아직 배정 전이면 "아직 시작 전이에요".
- 확인법: 화면 맨 위.

## 3. 줄마다 책을 단계 순서로
- 전에는: 없던 화면이에요.
- 지금은: 단어·구문·독해·문법 줄마다 "단어 1/5권 끝"과 책 칸이 1단계부터 가로로 나와요(옆으로 밀어서 봐요). 끝낸 책은 초록 "✓ 끝냈어요", 지금 하는 책은 파란 테두리 "📍 지금 여기"와 진행 막대, 다음에 할 책은 "다음 책", 나한테 배정 안 된 책은 흐리게. 두 단계에 걸친 책은 "5~6단계"로. 책을 누르면 "50과 중 23과 끝 (46%)".
- 확인법: 책 칸을 눌러 보세요.

## 4. 아래: 교재별 진행 상황(전부터 있던 것)
- 전에는: 그 화면이 "학습 진도"의 전부였어요.
- 지금은: 로드맵 아래에 "교재별 진행 상황" 제목으로 그대로 붙어 있어요. 진도 계산 규칙은 안 바꿨어요.

## 5. 서버가 아직 로드맵 자료를 안 줄 때
- 지금은: 위·가운데 대신 "🗺️ 1~7단계 로드맵은 준비 중이에요" 한 줄만 뜨고, 아래 교재별 진행 상황은 전처럼 보여요. 메뉴 줄 설명은 "내가 어디까지 왔는지".
- 확인법: 워커 14단계가 올라가기 전엔 이 상태가 정상이에요.

## 6. 차수 글자
- "학생앱 149차수 · 2026-11-04 · 마플 로드맵(1~7단계 내 위치)".

## 끝낼 때 확인한 것
- 설치와 빌드 성공을 확인했어요.
- 가짜 서버(7단계 커리큘럼 + 진도 맵: 워드마스터 베이직 완료, 워드마스터 수능 23/50과 진행 중, 천일문 기본 완료, 천일문 베이직-E 배정만)로 크롬에서: 메뉴 설명 "지금 5단계 (고1~고2)", 화면 "나는 지금 5단계 · 고1~고2", "지금 하는 책 · 단어-워드마스터-수능 23/50과", 📍 1개·✓ 2개·다음 책 1개, 수능 책 누르면 "50과 중 23과 끝 (46%)", "5~6단계" 표시, 아래 교재별 진행 상황 있음. 커리큘럼 없는 옛 워커 흉내 → "준비 중" 한 줄 + 교재별 진행 상황.

## 원장앱·워커가 보내 줘야 하는 것(14단계 지시문)
학생 자료 묶음(`/student-bundle`)에 `curriculum` 한 칸:
```
curriculum: {
  stages: [ { no: 1, name: "1단계", range: "초5~초6" }, … { no: 7, name: "7단계", range: "고3 심화" } ],
  lanes: [ { key: "voca", name: "단어", color: "#F2C14E", books: [ { id: "<진도 맵 책 id와 같게>", name: "단어-어휘끝-중등필수", alias: "어휘끝 필수", lessons: 40, stage: 2 }, { …, stage: 5, stageEnd: 6 } ] }, … ]
}
```
책 `id`가 진도 맵(ptree3) 책 id와 같으면 바로 맞고, 다르면 이름·별칭으로 맞춰요.

## 정한 것
- 내 단계 = 지금 하는 책(진행 중)의 단계 중 가장 높은 것 → 없으면 끝낸 책의 가장 높은 단계 → 없으면 배정된 첫 책의 단계 → 없으면 "시작 전".
- 책 상태(끝/진행 중/다음/잠김)는 전부터 있던 "학습 진도"와 똑같은 규칙(숙제 기록에서 과 번호 세기 + 원장 보정)이라 두 화면 숫자가 항상 같아요.
- 커리큘럼 자료 모양은 위처럼 정했고, 워커 14단계 지시문에 같은 모양을 적어요. 자료가 없으면 전처럼 교재별 진행 상황만 보여요.
- 원장 결정대로 main에 바로 올렸어요.
