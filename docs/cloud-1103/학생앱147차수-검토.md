# 학생앱 147차수 검토 — 앱 켤 때 뜨는 안내 카드 (2026-11-04)

원장 요청(11-04): 캐치테이블처럼 앱을 켜면 가운데 카드가 뜨게. 설문, 이번 주까지 통과할 단어 같은 것.

## 1. 앱을 켜면 안내 카드가 뜸
- 전에는: 앱을 켜면 바로 홈이 나왔어요. 설문이나 오답 기한은 홈 줄·더보기 숫자로만 보였어요.
- 지금은: 자료를 처음 받은 직후 가운데에 남색(급하면 빨간) 카드가 떠요. 큰 글씨 제목, 설명 한두 줄, 주황색 큰 단추 하나. 카드가 여러 장이면 오른쪽 위에 "1 / 4", 아래 점과 ‹ › 로 넘겨요. 카드 아래에 [오늘 하루 안 보기] [닫기].
- 확인법: 앱을 새로고침해 보세요(설문·오답·시험·공지 중 하나라도 있을 때만 떠요).

## 2. 뜨는 카드 종류와 순서(급한 것부터)
- 전에는: 없던 기능이에요.
- 지금은:
  1. 기한 지난 오답 단어 — 빨간 카드 "기한이 지난 단어가 있어요 / 틀린 단어 2개 · 10/25(일)까지였어요" [지금 복습하기] → 오답 복습.
  2. 이번 주까지 통과할 오답 단어 — "틀린 단어 3개, 이번 주까지! / 11/9(일)까지 통과해야 해요 (D-5)" [복습하러 가기].
  3. 응답 안 한 설문 — "설문이 기다리고 있어요 / 겨울방학 특강 시간 조사 · 11/9까지" [응답하기] → 공지·설문.
  4. 7일 안 시험 — "2학기 기말고사 D-3 / 11/7(토) ~ 11/9(월)" [시험 정보 보기].
  5. 새 고정 공지 — "새 공지가 있어요 / 공지 앞부분" [공지 보기]. 공지 하나당 한 번만 떠요.
  6. 원장이 올린 카드(워커가 `popups`를 주면) — 제목·글·사진·단추. 기간 안에만.
  최대 5장. 1·2번은 둘 중 하나만.
- 확인법: 더보기 숫자와 같은 자료라서, 더보기에 "응답할 설문 1개"가 있으면 카드도 떠요.

## 3. 닫기와 오늘 하루 안 보기
- 전에는: 없던 기능이에요.
- 지금은: [닫기]는 이번만 닫아요(탭을 옮겨도 다시 안 뜨고, 앱을 다시 켜면 다시 떠요). [오늘 하루 안 보기]는 지금 뜬 카드들을 오늘 하루 안 띄워요(폰에 기억). 큰 단추를 누르면 카드가 닫히고 그 화면으로 가요.
- 확인법: [오늘 하루 안 보기] 뒤 새로고침하면 안 떠요. 날짜가 바뀌면 다시 떠요.

## 4. 안 뜨는 경우
- 전에는: 해당 없음.
- 지금은: 선생님·원장이 학생 화면을 보기 전용으로 열었을 때는 안 떠요. 설문에 응답하거나 단어를 통과하면 그 카드는 다음에 안 떠요(자료가 바뀌니까).
- 확인법: 원장 마스터로 학생 화면을 열면 카드가 없어요.

## 5. 원장 카드 받을 준비(워커·원장앱은 13단계로 따로)
- 전에는: 해당 없음.
- 지금은: 학생 자료 묶음에 `popups` 칸이 오면 그대로 카드로 써요. 안 오면 아무 일도 없어요(옛 워커 그대로 돼요).
- 확인법: 워커가 올라간 뒤 원장앱에서 카드를 올리면 학생앱을 켤 때 떠요.

- 설치와 빌드 성공을 확인했어요.
- 가짜 서버(기한 지난 단어 2개 + 이번 주 단어 1개, 설문 1개, 3일 뒤 기말고사, 고정 공지 1개, 원장 카드 1개)를 붙인 크롬에서: 켜자마자 "1 / 5", 순서가 기한 지난 단어 → 설문 → 기말고사 D-3 → 새 공지 → 12월 단어왕 대회. [닫기] 뒤 탭을 옮겨도 안 뜨고, 새로고침하면 공지 카드만 빠진 "1 / 4". [지금 복습하기] → 오답 복습 화면(#vocabWrong). [오늘 하루 안 보기] 뒤 새로고침 → 안 뜸. 선생님 보기 전용 → 안 뜸.

## 정한 것
- "한 달 마지막 주에 통과할 단어"는 앱에 이미 있는 규칙(틀린 주의 다음 주 일요일까지)을 그대로 썼어요. 규칙 자체는 안 바꿨어요.
- 카드는 앱을 켤 때 한 번만 떠요(탭을 옮길 때마다 뜨지 않게). 자동 새로고침으로 자료가 바뀌어도 그 자리에서 새 카드가 튀어나오진 않아요.
- 시험 카드는 가장 가까운 시험 하나만, 7일 안일 때만 띄워요. 공지 카드는 가장 최근 공지 하나만, 한 번 본 공지는 다시 안 띄워요(폰에 기억 50개).
- 주황색 큰 단추는 토스·캐치테이블처럼 하나만 뒀고, 색은 남색 카드 위에서 잘 보이는 주황(#FF7A1A), 빨간 카드 위에서는 밝은 빨강(#FF5A3C)으로 했어요.
- 원장 카드(popups) 한 장의 모양은 `{ id, title, body, image, button, tab, url, startDate, endDate, icon }`로 정했어요. 워커·원장앱 13단계 지시문에 같은 모양을 적었어요.
