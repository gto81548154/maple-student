# 학생앱 171차수 검토 — 가짜 기록 막기 (2026-11-12)

앱 전체 버그 찾기(40개)에서 가장 급한 4개를 고쳤습니다.

## 고친 것

### 1. 단어 숙제 TEST를 한 문제만 풀고 통과하던 것
- 전에는: 숙제 TEST 도중 위쪽 [책장](또는 "마플보카" 글씨)을 누르면 "숙제 중" 표시가 안 꺼졌습니다. 그 뒤 아무 객관식을 한 문제만 풀어도 "오늘 단어 숙제 클리어!" 도장이 찍혔습니다.
- 이제는: 숙제 TEST 중에 [책장]을 누르면 "숙제 그만두기" 창이 먼저 뜹니다. 그리고 문제 화면을 벗어나는 모든 길에서 "숙제 중" 표시가 꺼집니다(통과 아님, 다음에 처음부터).
- 파일: `public/voca.html` (`hwAbort`, `goShelf`, `show`, `startSession`)

### 2. 원장님이 학생 화면의 단어 탭을 만지면 학생 기록이 바뀌던 것
- 이제는: 원장 보기로 학생을 열면 단어장이 **보기 전용**(`ro=1`)으로 열립니다. 책을 열거나 퀴즈를 풀어도 서버에도, 폰에도 저장되지 않습니다. 도장도 보내지 않습니다. 처음에 "보기 전용이에요 · 여기서 누른 것은 저장되지 않아요"라고 알려 줍니다.
- 보기 전용에서는 항상 서버에 있는 그 학생의 기록을 보여 줍니다.
- 파일: `src/screens/voca/VocaTab.jsx`, `public/voca.html`

### 3. 원장 주소를 다른 브라우저로 열면 그냥 학생으로 켜지던 것
- 전에는: 카카오톡 안에서 학생 화면을 본 뒤 [브라우저로 열기]를 누르면, 새 브라우저에는 원장 열쇠가 없어서 그 학생인 것처럼 켜졌습니다("앱 접속" 찍힘, 강의 시청·알림·숙제 TEST가 학생 것으로 남음).
- 이제는: 주소에 `master`가 있는데 폰에 원장 열쇠가 없으면, 학생 id·열쇠를 주소에서 떼고 **로그인 화면**(이름 + 전화번호 뒷 4자리)으로 보냅니다. 원장 열쇠가 있는 폰은 전과 똑같습니다.
- 파일: `src/core/auth.jsx`

### 4. 단어장 "수업이 멈춰 있어요" 화면의 이름 칸에 나쁜 코드를 넣을 수 있던 것
- 이제는: 주소에 실려 온 이름을 글자 그대로만 보여 줍니다.
- 파일: `public/voca.html`

## 확인한 것 (브라우저로 직접 돌려 봄, 가짜 서버)
- 빌드 성공.
- 숙제 중 표시: 다른 화면으로 가면 꺼짐 / 보통 공부를 시작하면 꺼짐 / [책장]을 누르면 확인 창이 뜨고, [그만두기]를 눌러야 책장으로 감.
- 보기 전용: 저장을 시켜도 서버로 올리는 요청 0번, 폰 저장 없음. 보통 학생 모드는 전처럼 저장·전송됨.
- 이름 칸: 나쁜 코드가 실행되지 않고 글자로만 보임.
- 원장 열쇠 없이 `?id=…&t=…&master=1`로 열면 주소가 `?master=1`로 바뀌고 로그인 화면이 뜸. 학생 자료 요청 0번. 열쇠가 있으면 주소 그대로.

## 아직 못 본 것
- **진짜 학생 자료·진짜 숙제 TEST로는 못 봤습니다.** 숙제 TEST를 처음부터 끝까지 실제로 풀어 본 것이 아니라, "숙제 중" 표시를 직접 켜 놓고 꺼지는지만 봤습니다.
- 원장 보기에서 실제 학생의 단어장이 보기 전용으로 잘 열리는지는 배포 뒤 원장님이 한 번 봐 주셔야 합니다.

## 남겨 둔 것
- 단어장이 주소의 `api`(서버 주소)를 검사 없이 믿습니다. 서버 주소가 바뀔 수 있어 이번에는 건드리지 않았습니다. 원하시면 "우리 워커 주소만 허용"으로 막을 수 있습니다.
- 선생님 보기의 단어장은 원래 서버에 저장이 안 되어서 그대로 뒀습니다.
