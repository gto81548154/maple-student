# 학생앱 186차수 검토 — 마플 포인트

워커 "11-21판 마플 포인트"가 올라가 있고, 원장앱에서 포인트를 **켠 뒤**에만 아래가 보입니다. 꺼져 있으면 학생 화면은 185차수와 똑같습니다.

## 1. 더보기에 "마플 포인트"가 생겼어요
- 전에는: 포인트가 없었어요.
- 지금은: 더보기 → 안내 칸에 "💰 마플 포인트"가 있고, 옆에 내 포인트가 보여요.
- 확인법: 더보기를 열어 "마플 포인트" 줄을 눌러 보세요.

## 2. 포인트 화면 — 상점
- 전에는: 없었어요.
- 지금은: 맨 위에 내 포인트와 "가장 싼 상품까지 얼마 남았는지" 막대가 보여요. 상품 카드를 누르면 아래에서 칸이 올라오고, 금액(1만·2만·3만원)을 골라 "주문"을 누르면 끝나요. 주문하면 포인트가 바로 빠지고 "내 주문"에 "기다리는 중"으로 떠요.
- 확인법: 마플 포인트 → 상점 → 편의점 카드 → 1만원 → 주문.

## 3. 주문 취소
- 전에는: 없었어요.
- 지금은: 원장님이 처리하기 전("기다리는 중")에는 "취소"를 누르면 포인트가 바로 돌아와요. 원장님이 보내면 "받았어요", 거절하면 이유와 함께 "거절됨 · 포인트 돌아옴"으로 바뀌어요.
- 확인법: 주문한 뒤 "내 주문"의 "취소"를 눌러 보세요.

## 4. 포인트 화면 — 내역 · 모으는 법
- 전에는: 없었어요.
- 지금은: "내역"에는 "12/3 제시간 등원 +100"처럼 한 줄씩 쌓여요. "모으는 법"에는 무엇을 하면 몇 포인트인지 표가 나와요(원장앱에서 바꾼 값 그대로).
- 확인법: 마플 포인트 → "내역", "모으는 법"을 눌러 보세요.

## 5. 홈에 내 포인트 한 줄
- 전에는: 없었어요.
- 지금은: 홈 맨 아래 카드(시험 정보·공지)에 "💰 마플 포인트 12,300P" 줄이 있어요. 누르면 포인트 화면으로 가요.
- 확인법: 홈을 맨 아래까지 내려 보세요.

## 6. 장학금·친구 소개 — 포인트로 받기
- 전에는: "1만원 기프티콘", "3만원 기프티콘"이라고 적혀 있었어요.
- 지금은: 포인트가 켜져 있으면 "10,000P", "30,000P"로 적혀요. 친구 소개는 "상담만 와도 3,000P, 등록하면 30,000P 더"라고 나와요.
- 확인법: 더보기 → 장학금·친구 소개 → 맨 위 안내 칸.

## 7. 성적 향상 장학금 신청
- 전에는: 없었어요.
- 지금은: 장학금 화면에 "성적 향상" 단추가 생겼어요. "중학생 · 10점 상승" 또는 "고등학생 · 1등급 상승"을 먼저 고르고, 지난 시험·이번 시험 성적과 성적표(정오표) 사진을 올려 신청해요. 10점(1등급)이 안 되면 신청 단추가 안 눌려요.
- 확인법: 장학금·친구 소개 → "성적 향상" → 지난 72, 이번 84를 넣어 보세요.

## 정한 것
- 포인트 계산은 전부 워커가 해요. 학생앱은 보여 주고 주문만 보내요.
- 워커가 옛 판이거나 원장님이 아직 안 켰으면 포인트 메뉴·홈 줄·"성적 향상" 단추가 아예 안 보여요.
- 상품에 사진이 없으면 그림 글자(이모지)로 보여요. 원장앱에서 사진 주소를 넣으면 사진이 나와요.
- 보기 전용 화면(원장·선생님이 학생 화면을 열었을 때)에서는 주문·취소가 안 돼요.
- 포인트 화면만 따로 띄워 보는 시험 틀을 `tests/browser/points-harness`에 두었어요.
- 이번에는 작업 가지(`claude/loving-hypatia-2lg0a7`)에만 올렸어요. main에는 원장님이 합치기를 누르면 올라가요.
