# 토익 개선 학생앱 배포

전에는: 토익 회차 답을 직접 채점해 개수를 적어야 했어요.
지금은: 답 입력과 채점, 파트별 결과, 틀린 답 확인을 준비했어요. 파트5 오답 복습과 유형별 정답률도 볼 수 있어요.
확인법: 원장 토익 탭에서 회차를 선택하거나 파트5 복습을 눌러 주세요.

전에는: 인터넷이 끊기면 기록 저장 여부를 알기 어려웠어요.
지금은: 기기 보관과 저장 대기 상태를 보여 주고 중복 제출을 막아요.
확인법: 답을 입력하고 답 저장을 누른 뒤 저장 상태를 확인해 주세요.

정한 것
- 사용자 요청으로 학생앱을 먼저 배포해요. 서버 코드는 사용자가 나중에 직접 올려요.
- 새 서버와 정답80회차가 준비되기 전에는 토익 기록 불러오기·저장·채점이 대기할 수 있어요.
- 토익 자동채점은 정답 비교 방식이며 유료 인공지능을 호출하지 않아요.
- 다른 앱의 코드는 바꾸지 않아요.
