# 학생앱 167차수 검토 (2026-11-12)

## 무엇을 고쳤나
열쇠(`&t=...`)가 빠진 옛 링크로 들어와도, 그 폰이 진짜 링크로 한 번이라도 들어온 적이 있으면 들어가지게 했습니다.

## 바뀐 것 1 — 열쇠 빠진 링크
- 전에는: `?id=학생번호`만 있는 링크를 누르면 서버가 거절 → 세 번 거절되면 "지금은 수업이 멈춰 있어요" 화면.
- 지금은: 폰이 기억해 둔 그 학생 열쇠를 주소에 자동으로 채워서 들어갑니다.
- 확인법: ① 진짜 링크(`&t=` 있는 것)로 한 번 연다 → ② 같은 브라우저에서 주소의 `&t=...`를 지우고 다시 연다 → 정상 화면이 뜨고 주소창에 `&t=`가 다시 붙어 있으면 성공.

## 바뀐 것 2 — 기억한 열쇠가 지워지던 실수
- 전에는: 열쇠 빠진 링크로 들어오면 폰에 저장해 둔 열쇠까지 빈칸으로 덮어썼습니다.
- 지금은: 덮어쓰지 않습니다. 학생별로 따로 기억합니다(한 컴퓨터에서 여러 학생을 열어도 됨, 최대 30명).
- 확인법: 위 확인법 ②를 한 뒤 홈 화면에 추가한 앱(주소 없이 열리는 것)을 열어도 그대로 들어가지는지 봅니다.

## 그대로인 것
- 처음 보는 폰(진짜 링크로 들어온 적 없는 폰)은 지금처럼 막힙니다 — 안전은 그대로.
- 카톡 안 창과 크롬·설치한 앱은 기억 공간이 따로라서, 각각 한 번씩은 진짜 링크로 들어와야 합니다.
- 열쇠를 재발급하면 옛 열쇠는 죽습니다. 새 링크로 한 번 들어오면 새 열쇠로 바뀝니다.
- 서버(마플싱커)는 안 건드렸습니다.
