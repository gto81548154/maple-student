# 학생앱 180차수 검토 — 선생님 화면 손질 (2026-11-19)

원장 요청(11-19, 새 화면을 써 본 뒤): 아이콘을 학생용과 같게 · 캘린더에서 수업 학생 빼기 · 단어 선별 색을 내 단어장과 같게 · 단원은 누르면 바로 들어가고 여러 개는 [선택]으로.

## 바꾼 것

### 1. 선생님 화면 아이콘을 학생앱과 같은 그림으로
- 브라우저 탭 아이콘, 아이폰 홈 화면 아이콘이 초록 → 학생앱과 같은 남색.
- 안드로이드·PC에 "앱으로 설치"했을 때의 아이콘은 서버(워커)가 정한다. 고친 워커 사본에 같이 넣어 원장님께 전달(올려야 바뀜). 이미 깔아 둔 아이콘은 지우고 다시 깔아야 바뀔 수 있다.
- 깔리는 앱 이름("마플쌤")과 학생앱과 따로 깔리는 것은 그대로.
- 파일: `src/core/pwa.jsx`

### 2. 캘린더: 수업 학생 명단을 빼고 그 달 근무일 모음으로
- 날짜를 고르면 나오던 "수업 학생" 명단을 뺐다(학생은 [학생] 탭에서 본다).
- 그 자리에 보고 있는 달의 근무일 수와 날짜·출근 시간 모음. 날짜를 누르면 달력에서 그 날이 골라진다. 달력 칸과 같은 규칙(휴원일 제외, 추가 근무 포함).
- 이것은 **근무 예정표**다. 실제로 몇 시에 왔는지 적는 출근 기록은 아니다(그런 자료가 지금 없다).
- 원장·선생님 캘린더가 같은 화면이라 원장 화면에서도 같이 바뀐다. 원장의 근무 고치기(길게 누르기)는 그대로.
- 파일: `src/screens/teacher/TeacherCalTab.jsx`

### 3. 단어 선별 화면을 내 단어장과 같은 색·모양으로
- 선별 탭만 예전 모습(회색 바탕, 각진 검정 단추)이었다. 이제 내 단어장과 같은 바탕·카드·단추 모양.
- 선별 동작(유닛 고르기 → 단어 체크 → 저장)은 그대로.
- 파일: `public/voca.html`

### 4. 선생님·원장 단어장: 단원을 누르면 바로 들어가기 + [선택]
- 전에는: 단원(DAY)을 누르면 체크되고, 아래에서 방식을 고른 뒤 시작 단추.
- 이제는: 단원을 누르면 바로 "어떻게 공부할까요?" 창이 떠서 방식만 고르면 시작.
- 여러 단원을 묶으려면 [선택] → 체크 방식으로 바뀌고 [전체 선택] · [선택 해제] · [닫기]. 이때는 전처럼 아래에 방식·시작 단추가 나온다.
- 숙제 카드로 들어와 범위가 미리 체크돼 있으면 처음부터 선택 방식으로 열린다.
- **학생 화면은 그대로**(누르면 체크). 선생님·원장에게만 적용했다.
- 파일: `public/voca.html`

## 확인한 것 (가짜 서버를 붙여 폰 크기 화면으로 눌러 봄)
| 경우 | 결과 |
|---|---|
| 선생님 화면 아이콘 주소 | 학생앱 아이콘 |

| 단원 하나 누르기 | 그 단원 이름으로 방식 창이 뜸 → 카드 고르면 카드 화면으로 |

| 학생 id로 연 단어장 | 누르면 체크(전과 같음), [선택] 단추 줄 안 보임 |

## 아직 못 본 것
- 진짜 서버와 붙여 본 것이 아니다. 캘린더의 근무일 모음은 가짜 자료에 근무일이 없어 "0일" 화면만 봤다(근무일이 채워진 모양은 못 봄).
- 단어 선별 화면은 폭이 좁으면 위 제목(책 이름)이 두 줄로 꺾인다.
