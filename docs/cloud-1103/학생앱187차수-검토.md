## 눌러 보며 확인하는 법

준비 목록을 올리고, 앱이 새 판으로 올라간 뒤에:

1. 학생 링크로 마플보카를 연다 → 책장에 「더블보카 Core」「더블보카 Pro」가 보인다.
2. Core를 누른다 → DAY 01~40이 보이고, DAY 05·10·15…40은 "40개", 나머지는 "20개"다.
3. DAY 01을 누른다 → 카드 / 블링크 / 객관식 / 시험 네 가지가 뜬다.
   - 카드: 누르면 뒷면에 뜻과 반의어·파생어·짝꿍 줄이 나온다(없는 단어는 그 줄이 안 나온다).
   - 객관식: 보기가 나오고 정답을 고를 수 있다.
   - 시험: 뜻을 직접 쓴다.
4. Core에서 몇 단어 맞힌 뒤 책장으로 나온다 → Core에만 "1회독 진행 중"이 붙고, 다른 책은 그대로다.
5. 숙제에 "단어-더블보카 Core 5 6 7 8"을 넣는다 → 홈 "수업 단어 공부" 카드에 "더블보카 Core DAY 5~8"이 뜬다.
6. 단어 검색에서 allow를 찾는다 → "더블보카 Core · DAY 1"이 붙은 결과가 나온다.
7. 옛 책(워마 수능·Basic·하이스트·어휘끝 3권)을 하나씩 열어 본다 → 전과 같다.
