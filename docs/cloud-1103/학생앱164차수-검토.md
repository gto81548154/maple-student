# 학생앱 164차수 검토 — 달력 아래 "남은 수업" 목록

그림: 164차수-달력.png (왼쪽 = 펼친 달력, 가운데 = 접은 달력, 오른쪽 = 지난 날짜를 누른 모습)

## 1. 달력 아래에 이번 달 남은 수업이 쭉 나와요
전에는: 달력 아래에 누른 날 하루만 나왔어요. 처음에는 오늘 하루("6:00 등원 예정")만 보였어요.
지금은: 처음에는 "11월 남은 수업" 목록이 나와요. 오늘부터 이번 달 끝까지 오는 날과 시간이 한 줄씩 보여요. 보강이나 시간이 바뀐 날에는 "보강", "시간변경" 표시가 붙어요.
확인법: 학생 화면 홈 → "다음 수업 안내" 카드의 달력 아래를 봐요. 더보기 → 수업 일정에서도 똑같이 나와요.

## 2. 지난 수업은 목록에 안 나와요
전에는: 목록이 없었어요.
지금은: 어제까지의 수업은 목록에서 빠져요. 오늘 수업은 오늘 밤까지 남아 있고, 내일이 되면 빠져요.
확인법: 목록 맨 위가 오늘(또는 오늘 이후 첫 수업)인지 봐요.

## 3. 달을 넘기면 그 달 수업이 나와요
전에는: 달을 넘겨도 아래 칸은 그대로였어요.
지금은: ▶ 를 누르면 "12월 수업"이 쭉 나와요. ◀ 로 지난 달에 가면 "지난 달이에요."라고 나와요.
확인법: 달력 위 ◀ ▶ 를 눌러 봐요.

## 4. 날짜를 누르면 그날 기록이 나와요 (출석·지각·결석)
전에는: 날짜를 누르면 그날 기록이 나왔어요. 다른 날을 누르기 전에는 돌아갈 곳이 없었어요.
지금은: 날짜를 누르면 전처럼 그날 기록이 나와요. 지각한 날은 "몇 분 지각"과 도착 시간, 결석한 날은 "결석"과 사유, 온 날은 "출석"과 등원·하원 시간이 보여요. 같은 날짜를 한 번 더 누르거나 "남은 수업 보기 ›"를 누르면 목록으로 돌아와요. 목록의 줄을 눌러도 그날로 가요.
확인법: 지각·결석이 있는 날짜를 눌러 봐요 → "남은 수업 보기 ›"를 눌러 봐요.

## 5. 달력을 접었을 때
전에는: 접으면 2주만 보이고 아래에는 오늘 하루만 나왔어요.
지금은: 접으면 "2주 안 남은 수업"만 나와요. 보이는 2주 안의 수업만 적어요.
확인법: 홈 카드 맨 아래 "접기 ▲"를 눌러 봐요.

정한 것
- 처음에는 아무 날짜도 고르지 않은 상태로 시작해요(전에는 오늘이 골라져 있었어요). 그래야 목록이 먼저 보여요.
- 목록의 시간은 날짜를 눌렀을 때 나오는 글자와 같은 모양(6:00)으로 적었어요.
- 쉬는 날(휴원), 등원이 취소된 날, 결석 처리된 날은 목록에 안 나와요.
- 시험 기간에 오는 수업에는 "시험기간" 표시가 같이 붙어요.
- 지각·결석·출석 기록 보기는 전부터 있던 기능이라 새로 만들지 않고, 잘 나오는지만 확인했어요.
