# 학생앱 163차수 검토 — 공지 창 "앞으로 안 보기"

## 1. 공지 창에 "앞으로 안 보기" 단추
전에는: 공지 창은 한 번 뜨면 끝이었어요. 닫기만 눌러도 그 공지는 다시 안 떴어요.
지금은: 공지 카드 아래 왼쪽 단추가 "앞으로 안 보기"예요. 이걸 눌러야만 그 공지가 다시 안 떠요. "닫기"나 창 바깥을 눌러서 끄면 다음에 앱을 켤 때 또 떠요.
확인법: 학생 화면으로 앱을 켜요 → 공지 창에서 "닫기" → 앱을 껐다 켜면 또 떠요 → 이번엔 "앞으로 안 보기" → 껐다 켜도 안 떠요.

## 2. 창으로 뜨는 공지는 가장 최근 1개만
전에는: 새 폰으로 들어가면 옛 공지가 앱을 켤 때마다 하나씩 차례로 떴어요.
지금은: 가장 최근 공지 1개만 창으로 떠요. 그것도 올린 지 한 달 안의 것만 떠요. 옛 공지는 공지 화면에 들어가면 그대로 볼 수 있어요.
확인법: 공지가 여러 개 있는 학생으로 켜요 → 창에는 가장 최근 것 하나만 나와요 → 홈의 "공지"를 누르면 옛 공지도 다 보여요.

## 3. 단어·설문·시험 카드는 그대로
전에는: 왼쪽 단추가 "오늘 하루 안 보기"였어요.
지금은: 똑같아요. 단어 경고, 설문, 시험 카드는 "오늘 하루 안 보기"만 있어요. "앞으로 안 보기"는 공지 카드에만 있어요.
확인법: 카드가 여러 장 뜨는 학생으로 켜요 → ‹ › 로 넘기면 공지 카드에서만 단추 글자가 "앞으로 안 보기"로 바뀌어요.

정한 것
- 공지 카드에서 "앞으로 안 보기"를 누르면 그 공지 카드만 빠지고, 다른 카드가 남아 있으면 창은 그대로 있어요.
- "앞으로 안 보기"는 그 폰에만 기억돼요. 폰을 바꾸거나 앱을 지웠다 깔면 최근 공지 1개가 한 번 더 떠요.
- 새 공지가 올라오면 전에 "앞으로 안 보기"를 눌렀던 학생에게도 새 공지는 떠요.
- 이번 판을 올리면, 지금 올라와 있는 가장 최근 공지(한 달 안)가 학생들에게 한 번 더 떠요. 예전에 닫기로만 껐던 것이라서 그래요.
- 공지 카드 제목을 "새 공지가 있어요"에서 "공지가 있어요"로 바꿨어요. 여러 번 뜰 수 있어서요.
