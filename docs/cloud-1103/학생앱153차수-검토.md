# 학생앱 153차수 검토 — 단어 숙제를 안 했으면 앱 켤 때 안내 카드 (원장 11-06 요청)

화면 캡처: `docs/cloud-1103/153차수-단어숙제카드.png`(폰 크기)

## 1. 단어 숙제 안내 카드

- 전에는: 단어 숙제를 안 해도 홈의 "지금 폰으로 할 공부"에 빨간 글("아직 안 봄")만 있었습니다. 앱을 켤 때 뜨는 안내 카드(오답 단어·설문·시험·새 공지)에는 단어 숙제가 없었습니다.
- 지금은: 다음(또는 오늘) 수업 숙제에 앱 단어 숙제가 있는데 아직 통과 안 했으면, 앱을 켤 때 빨간 카드가 가운데 뜹니다. "📘 단어 숙제를 아직 안 했어요 · 워마 수능 DAY 33~35 · 11/6(금) 수업 전까지 숙제 TEST를 통과해요." [숙제 TEST 시작]을 누르면 바로 숙제 TEST가 열립니다. 다른 안내 카드와 같이 뜨면 단어 숙제 카드가 맨 앞입니다.
- 확인법: 단어 숙제를 안 한 학생 링크로 앱을 켜 보세요. 숙제를 통과한 뒤 다시 켜면 카드가 안 뜹니다.

## 2. 안 뜨는 경우

- 숙제를 이미 통과했을 때, 지난 날짜 숙제일 때, 숙제에 앱 단어가 없을 때는 안 뜹니다.
- [오늘 하루 안 보기]를 누르면 그날은 다시 안 뜨고, 다음 날 아직 안 했으면 또 뜹니다.
- 선생님·원장이 학생 화면을 열어 볼 때는 안 뜹니다(다른 안내 카드와 같음).
- 통과 도장을 확인하기 전에는 띄우지 않습니다. 도장이 늦게 오면 통과한 학생에게 "안 했어요"가 잘못 뜰 수 있어서, 앱을 켠 뒤 도장 확인을 최대 5초 기다립니다. 5초 안에 확인이 안 되면 단어 숙제 카드만 빼고 나머지 안내 카드를 띄웁니다.

## 그 밖에

- 로딩 화면 글자: "학생앱 153차수 · 2026-11-06 · 단어 숙제 안 했으면 앱 켤 때 안내 카드(📘 숙제 TEST 시작)".
- `npm install` → `npx vite build` 통과. 카드 규칙 10가지(내일 숙제·오늘 숙제·통과·도장 확인 전·지난 숙제·숙제 없음·내신 단어·맨 앞 순서·오늘 하루 안 보기·다음 날)를 따로 돌려 확인했습니다.
- 이건 **앱 안에서 뜨는 카드**입니다. 앱을 안 켠 학생에게 폰 알림(푸시)을 보내는 건 워커가 해야 하는 일이라 이번엔 안 했습니다.

## 정한 것

- 카드 색은 기한 지난 오답 단어와 같은 빨강(급한 것)으로 했습니다.
- 도장 확인 기다리는 시간은 5초입니다. 너무 길면 다른 안내 카드가 늦게 뜨고, 너무 짧으면 단어 숙제 카드가 자주 빠집니다.
