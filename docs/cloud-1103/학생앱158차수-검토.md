# 학생앱 158차수 준비본 · 토익 5차

## 정답 원문 대조
전에는: 80회차·8,000문항의 정답이 검토 전 초안이었어요.
지금은: 원본 책의 정답표 이미지와 대조해 정답본으로 확정했어요. 주의 표시 1,192곳도 모두 확인했어요.
확인법: 보존한 정답본과 회차별 검토 기록에서 원본 책·쪽수·정답을 확인할 수 있어요.

## 검토 누락 차단
전에는: 검토가 끝났는지 사람이 기록해야 했어요.
지금은: 빠진 회차·문항, 바뀐 원본, 원문 회차 불일치, 필요한 직접 확인 기록 누락이 있으면 확정본을 만들 수 없어요.
확인법: 검토 절차 테스트 7개와 확정본 80회차 검사 모두 통과했어요.

## 검토 결과와 정한 것
- 전체 정답표를 이미지로 다시 읽어 대조했어요. 인식이 빠지거나 신뢰도가 낮은 37문항은 확대해서 직접 확인했어요.
- 4권은 이미지 인식만 사용한 초안이어서, 20회차의 정답표 화면 전체도 추가로 확인했어요.
- 정답 후보 자체를 바꿔야 할 차이는 없었어요. 기존 주의 표시는 검토 이력에 남겼어요.
- 원본 전체 책 8개와 분할 PDF 80개가 검토 후 바뀌지 않았는지도 확인했어요.
- 앱에 배포된 해설 파일과의 최종 일치 확인은 배포 전 점검에 남아 있어요.
- 실제 답 입력·자동채점 화면은 다음 6차에 연결해요. 배포는 8차에 해요.
