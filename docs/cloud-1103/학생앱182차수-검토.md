# 학생앱 182차수 검토 — 퇴근·원장 고치기·달별 모음 + 블랙홀 우주 효과 (2026-11-19)

원장 결정(11-19): 출근 기록에 퇴근·원장 고치기·달별 모아보기를 다 넣는다. 블랙홀에 우주 효과를 살짝 넣는다.

## 바꾼 것

### 1. 퇴근 기록
- [출근]을 누른 뒤에는 [퇴근] 단추가 나온다. 누르면 그 시각이 적히고 "17:52 출근 · 22:10 퇴근 / 4시간 18분 근무"로 보인다.
- 잘못 눌렀으면 [퇴근 취소](퇴근만 지움, 출근은 남음). 퇴근을 누르기 전에는 전처럼 [취소]로 출근을 지울 수 있다.
- 캘린더 근무일 칸에 "✓ 17:52–22:10", 달 줄에 "출근 기록 N일 · 총 시간".

### 2. 원장이 기록을 고치기
- 원장 캘린더에서 날짜를 고르면 선생님 전원이 나온다(기록 없는 사람은 "기록 없음"). [고치기] → 출근·퇴근 시각을 넣고 [저장], 또는 [기록 지우기].
- 원장이 적거나 고친 기록에는 "고침" 표시가 붙고, 선생님 화면에는 "원장님이 적음"으로 보인다.
- 미래 날짜는 못 적는다(단추가 안 나온다). 시각은 24시간으로 넣는다(저녁 6시 = 18:00).
- 선생님 링크로는 고칠 수 없다(서버가 원장 링크만 받는다).

### 3. 달별 모아보기
- 원장 캘린더 아래 "N월 선생님 출근 모음": 선생님마다 출근 일수 · 총 근무 시간 · 퇴근이 안 적힌 날 수. 달력을 넘기면 그 달로 바뀐다.
- 총 시간은 퇴근까지 적힌 날만 더한다.

- 파일: `src/screens/teacher/TeacherCheckin.jsx`, `TeacherCalTab.jsx`, `useTeacherActions.jsx`, `TeacherHome.jsx`
- 서버(워커 사본): `/teacher/checkin`에 퇴근·퇴근 취소, 새 문 `/teacher/checkin-edit`(원장만), 원장 홈 응답에 기록 없는 선생님도 포함, `checkinV: 2`.
- 앱은 서버가 `checkinV >= 2`일 때만 [퇴근]·[고치기]를 보인다. 181차수 워커(1판)에 붙으면 출근만 된다.

### 4. 블랙홀 우주 효과
- 블랙홀 모드의 바탕에만: 별(가만히 있는 층 + 천천히 깜빡이는 층), 옅은 보라·주황 성운, 오른쪽 위에서 아주 천천히 도는 은하 빛, [블랙홀]을 누르는 순간 0.7초 밝았다 가라앉는 전환.
- 큰 카드와 단원 줄은 살짝 비치게 했다. 글자 색·크기는 그대로.
- 기기에서 "움직임 줄이기"를 켜 두면 움직이지 않는다.
- 학생·선생님·원장 모두에게 보인다(같은 단어장 화면).
- 파일: `public/voca.html`

## 아직 못 본 것
- 진짜 서버와 붙여 본 것이 아니다.
- 블랙홀 효과는 컴퓨터의 폰 크기 화면에서만 봤다. 실제 오래된 폰에서 버벅이는지는 못 봤다(움직이는 것은 투명도와 회전 두 가지뿐이라 가벼운 편).
- 블랙홀의 시험·객관식 화면은 따로 찍어 보지 않았다(바탕만 바뀌므로 같은 모양일 것).
