바뀐 것마다 "전에는 / 지금은 / 확인법" 세 줄로 적었습니다.

**원장이 새 판을 올린 뒤 학생 폰에서 띠가 뜨기까지:** 학생이 앱을 새로 켜거나, 다른 데 갔다가 다시 앱 화면으로 돌아오면 몇 초 안에 "🆕 업데이트가 있어요" 띠가 떠요. 앱을 계속 켜 둔 채로 있으면 길어야 30분 안에 떠요. (배포가 끝나 새 판 번호 파일이 올라간 다음부터 셉니다.)

## 1. 앱마다 "판 번호"(빌드 시각)가 생김
- 전에는: 앱에 자기가 몇 번째 판인지 적혀 있지 않아서, 새 판이 올라와도 옛 판인지 알 길이 없었어요.
- 지금은: 앱을 만들 때마다 그 시각이 판 번호로 앱 안에 박히고, 같은 번호가 서버의 작은 판 번호 파일에도 적혀요. 이 파일은 만들 때마다 새로 생기는 것이라 깃에는 넣지 않도록 했어요.
- 확인법: 더보기 > 앱 설정 맨 아래 "지금 보는 판: 2026-11-03 16:40 판"처럼 작게 보여요.

## 2. 새 판을 알아채는 길이 하나 더 생김
- 전에는: 푸시 알림용 부품이 바뀔 때만 새 판을 알아챘는데, 그 부품은 배포 때 거의 안 바뀌어서 띠가 안 떴어요.
- 지금은: 앱이 켜질 때, 화면이 다시 보일 때, 그리고 30분마다 서버의 판 번호 파일을 새로 읽어서 내 판 번호와 다르면 띠를 띄워요. 인터넷이 안 되거나 읽기에 실패하면 조용히 넘어가요. 예전 길(푸시 부품)도 그대로 있어요.
- 확인법: 새 판을 올린 뒤 학생 폰에서 앱을 다시 열면 위쪽에 띠가 떠요.

## 3. 띠 글과 단추가 바뀜
- 전에는: "🆕 새 버전이 있어요. 하던 일을 마친 뒤 업데이트해 주세요." + [업데이트].
- 지금은: "🆕 업데이트가 있어요" + [지금 적용]. 누르면 캐시(폰에 남은 옛 화면 조각)를 전부 비우고 새로고침해서 새 판이 떠요. 푸시 부품이 기다리는 중이면 전처럼 그 길로 바꿔요. 시험·영상 중이면 전처럼 안내만 하고 바꾸지 않아요.
- 확인법: 띠의 [지금 적용]을 누르면 화면이 한 번 새로 뜨고 띠가 사라져요.

## 4. 더보기 > 앱 설정에 [앱 새로고침] 단추
- 전에는: 옛 화면이 남아도 학생이 스스로 풀 방법이 없었어요.
- 지금은: "🔄 앱 새로고침" 칸이 항상 보여요. 설명은 "화면이 이상하거나 옛날 화면이 보이면 눌러 주세요". 누르면 3번과 똑같이 캐시를 비우고 새로고침해요. 시험·영상 중이면 안내만 해요. 바로 아래에 지금 보는 판 번호가 작게 적혀 있어요.
- 확인법: 더보기 > 앱 설정으로 가서 맨 아래 칸을 보세요.

- 확인법: 더보기 > 앱 설정 "🆕 앱 업데이트" 칸.
