# 학생앱 175차수 검토 — 연결·강의 시청 기록 바로잡기 (2026-11-12)

## 고친 것

### 1. 서버가 한 번 잘못 답하면 멀쩡한 화면이 옛 저장본으로 바뀌던 것
- 전에는: 서버가 "그런 학생 없음"(403/404)을 한두 번 잘못 답하면, 지금 보던 화면을 폰 저장본으로 바꿨습니다. "저장해 둔 옛날 것이에요" 안내가 뜨고, 저장본이 없으면 연결 오류 화면이 됐습니다.
- 이제는: **지금 화면을 그대로 둡니다.** 세 번 연속이면 전처럼 차단합니다. 이 경우는 다음 확인을 늦추지 않습니다.
- 파일: `src/state/useBundleLoader.jsx`

### 2. 강의를 열 때 인터넷이 잠깐 끊기면 계속 안 열리던 것
- 전에는: 유튜브 플레이어 불러오기에 한 번 실패하면, 앱을 완전히 껐다 켤 때까지 모든 강의가 "플레이어를 불러오지 못했습니다"였습니다.
- 이제는: 실패 기록을 치우고, 다음에 강의를 열 때 다시 불러옵니다.
- 파일: `src/core/videoWatch.jsx`

### 3. 폰에서 시청률이 실제보다 높게 보이던 것
- 전에는: 저장에 실패한 조각을 화면에 한 번 더하고, 나중에 다시 보낼 때 또 더했습니다(서버 기록은 맞았음).
- 이제는: 이미 화면에 더한 조각은 다시 더하지 않습니다.
- 또, 앱을 켜자마자 밀린 조각을 보낸 직후에 그 조각(몇 초)이 서버의 전체 시청 시간을 가리던 것 → "본 시간이 더 많은 쪽"을 씁니다.
- 파일: `src/state/useVideoSession.jsx`, `src/core/videoWatch.jsx`

### 4. 자동 저장이 가는 중에 강의를 닫으면 마지막 몇 초가 빠지던 것
- 이제는: 가는 중인 저장 뒤에 본 몇 초를 따로 폰 대기열에 넣어, 다음 기회에 보냅니다.
- 파일: `src/state/useVideoSession.jsx`

### 5. 옛 자료 안내가 사라지던 것
- 전에는: 폰 저장본(옛 자료)을 보는 중에 연결이 또 실패하면 안내가 "연결이 잠시 늦어지고 있어요"로 바뀌어, 옛 자료라는 표시와 저장 날짜가 사라졌습니다.
- 이제는: 옛 자료를 보는 동안에는 날짜가 적힌 안내를 그대로 둡니다.
- 파일: `src/state/useBundleLoader.jsx`

### 6. 탭을 닫을 때 같은 시청 초가 서버에 두 번 갈 수 있던 것
- 탭 닫기 저장 바로 뒤에 "화면 가려짐" 저장이 같은 초를 또 보낼 수 있었습니다(주로 컴퓨터).
- 이제는: 탭 닫기 저장이 "여기까지 저장함"을 표시해서 뒤따르는 저장은 보낼 것이 없습니다.
- 파일: `src/state/useVideoSession.jsx`

## 확인한 것 (가짜 서버를 붙여 브라우저로 직접 돌림)
| 경우 | 결과 |
|---|---|
| 저장 실패 → 대기열 → 다시 보내기 | 화면 시청 시간 30초 그대로(전에는 60초가 됨). 서버에는 1번만 감 |
| 자동 저장이 가는 중(20초)에 27초에서 닫기 | 대기열에 7초가 남고, 끝나면 화면 27초 · 서버에 20초 + 7초 |
| 탭 닫기 → 화면 가려짐 | 대기열에 12초 한 번, 서버로 또 보내는 것 0번 |
| 유튜브 불러오기 실패 → 인터넷 복구 뒤 다시 | 같은 화면에서 다시 불러와짐 |
| 시청 시간 합치기 | 서버 500초 vs 폰 12초(더 최근) → 500초, 폰 530초 → 530초 |

- 빌드 성공. 검사 틀은 `tests/browser/videoSession-harness`(포트 5198)에 남겼습니다.
