# 학생앱 168차수 검토 — 더보기 "안 쓰는 기능" 칸 + 새 팝업(준비 중)

작업 가지: `claude/lab-popup-168` (아직 실제 앱에는 안 올렸어요.)

## 한 줄로
새 팝업을 만들어 두기만 했어요. 앱을 켤 때 저절로 뜨지 않고, 더보기 맨 아래 "안 쓰는 기능"에서 눌러야만 열려요.

## 바뀐 것
### 1. 더보기 맨 아래에 "안 쓰는 기능" 칸
- 전에는: 안내 · 학습 · 앱 세 칸.
- 지금은: 그 아래에 "안 쓰는 기능" 칸이 하나 더 있고, 안에 [새 팝업 (준비 중)] 한 줄이 있어요.
- 확인법: 학생앱 → 더보기 → 맨 아래.

### 2. 새 팝업 (파스텔 색 · 탭 3개)
- [공지]: 지금 올라온 공지를 날짜와 함께 보여 줘요(4개까지). [공지 전체 보기] → 공지·설문 화면.
- [시험 일정]: 가장 가까운 내신 시험 D-day, 시험 범위, 숙제 몇 개 중 몇 개 끝, 오늘/다음 수업. [숙제 보러 가기] → 숙제 탭.
- [단어 리그]: "준비하고 있어요" 안내만 나와요. 순위·상품·이름은 아직 없어요(가짜 숫자를 보여 주지 않으려고).
- 전부 앱이 이미 받아 둔 자료로 그려요. 서버에 새로 묻지 않아요.

### 3. 안 바뀐 것
- 지금 쓰는 "앱 켤 때 안내 카드"(오답 단어·설문·시험·공지)는 그대로예요.
- 원장앱·마플싱커(워커)는 손대지 않았어요.

## 검사한 것
- 빌드 성공.
- 가짜 화면(폰 너비)에서: 더보기에 칸이 보임 → 누르기 전에는 팝업 없음 → 누르면 열림 → 탭 3개 → 단추로 이동 → Esc·닫기 → 공지·시험이 없을 때 안내 글. 옆으로 안 넘침, 오류 없음.
- 진짜 학생 자료로는 아직 안 봤어요(배포 뒤 확인).

## 원장님이 결정해야 하는 것
1. "안 쓰는 기능" 칸을 누구에게 보일지
   - 모든 학생에게 보이기(지금 코드): 학생도 눌러 볼 수 있어요. 안에 가짜 정보는 없어요.
   - 원장님·선생님 화면에서만 보이기(추천): 학생에게는 안 보여요. 한 줄만 고치면 돼요.
2. 배포: "배포해" 하시면 학생앱에 올려요.
