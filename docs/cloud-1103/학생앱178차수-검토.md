# 학생앱 178차수 검토 — 선생님 화면 학생앱 모양 + 선생님 보카바이블 (2026-11-19)

원장 요청(11-19): 선생님·원장 화면을 학생앱처럼 보이게, 선생님도 보카바이블로 공부할 수 있게.

## 바꾼 것

### 1. 선생님·원장 화면의 겉모습을 학생 화면과 같게
- 머리글: 남색 큰 머리글 → 학생 화면과 같은 작은 머리글(MP + 이름 + 직책 + 날짜, 오른쪽 [새로고침]).
- 탭 줄: 위쪽 줄 → 학생 화면과 같은 **화면 아래 붙박이 탭**. 탭 구성(홈·캘린더·단어장·강의·학생, 원장은 토익)과 안의 내용은 그대로.
- 색: 선생님·토익 화면에 따로 적혀 있던 바탕·글자·테두리·파랑을 학생앱 공통 색으로 바꿈. 앞으로 학생앱 색을 바꾸면 선생님 화면도 같이 바뀜.
- 머리글 오른쪽의 "원장 전용 / 선생님 전용" 글자는 뺌(이름 자리에 이미 "원장" / "○○ 선생님"이 나옴).
- 파일: `src/screens/teacher/*`, `src/screens/toeic/*`, `src/ui/StudentChrome.jsx`(설명 글만)

### 2. 선생님 [내 단어장]에 보카바이블
- 전에는: 선생님 책장에서 보카바이블을 아예 숨김(08-27 원장 지시).
- 이제는: 선생님 [내 단어장]에서 조건 없이 바로 열림. "히든" 표시 없이 보통 책처럼 보임.
- [단어 선별]에는 전처럼 안 나옴(학생 숙제 단어를 고르는 곳).
- 학생 쪽 규칙(배정받았거나 하이스트 3회독)은 안 건드림.
- 파일: `public/voca.html`

## 확인한 것 (가짜 서버를 붙여 폰 크기 화면으로 직접 열어 봄)
| 경우 | 결과 |
|---|---|
| 선생님 링크 — 홈·캘린더·단어장·강의·학생 | 다섯 탭 모두 열림, 아래 탭 줄에 안 가림 |
| 원장 링크 — 위 다섯 + 토익 | 여섯 탭이 폭 390에서 한 줄에 들어감 |
| 선생님 [내 단어장] | 보카바이블이 책장 맨 위에 보임 |
| 선생님 [단어 선별] | 보카바이블 없음, 다른 책은 그대로 |
| 원장 [내 단어장] | 보카바이블 그대로 보임 |

- 빌드 성공.

## 아직 못 본 것
- **진짜 서버와 붙여 본 것이 아닙니다.** 자료가 채워진 화면(오늘 할일·학생 명단·근무표 고치기 창·토익 답안지)은 색만 바뀐 것이라 눌러 보지는 않았습니다.
- 보카바이블은 선생님의 단어장 이름이 `__teacher__`로 시작할 때 열립니다. 서버가 다른 이름을 내려주는 선생님이 있다면 그 선생님에게는 안 보입니다(서버 코드는 못 봄).

## 안 건드린 것
- 원장 전용 입구(`?master=1`, 마스터 홈)의 모양은 그대로입니다.
- 선생님 토익 열기·주소 하나 + 로그인은 서버(워커)를 같이 고쳐야 해서 다음으로 미룸.

## 쉬운 요약
선생님·원장 화면이 학생앱과 같은 머리글·아래 탭·색으로 바뀌었고, 선생님도 내 단어장에서 보카바이블을 열 수 있습니다.
