# 공통 규칙 (모든 단계에 적용)

- 학생앱(maple-student)은 React + Vite. 화면 글은 전부 한국어(학생용, 존댓말). 기존 코드 스타일(인라인 style, UI 토큰, TAP 크기)을 그대로 따른다. 토스 스타일(140차수)로 이미 바뀐 홈 화면의 분위기를 유지한다.
- `public/voca.html`(마플보카)은 한 파일짜리 순수 HTML/JS 앱이다. 거기 규칙(전역 S·W·Q 등)을 그대로 따른다.
- 지시한 것만 고친다. 다른 기능·파일은 건드리지 않는다.
- 줄끝은 LF 그대로.
- 끝낼 때: `npm install` → `npx vite build` 성공 확인.
- 깃: 작업이 끝나면 **항상 main에 바로 커밋하고 올린다**(원장 결정 11-04). 작업 환경이 다른 가지를 지정해 주면 그 가지에도 올리되, main에 올리는 것을 빼먹지 않는다.
- `docs/cloud-1103/학생앱<차수>차수-검토.md`를 만들어 같이 커밋한다. 중학교 1학년도 알아들을 쉬운 한국어로, 바뀐 것마다 "전에는 / 지금은 / 확인법(어디를 눌러 보면 되는지)" 세 줄씩. 함수 이름·줄 번호·영어 용어는 적지 않는다.
- 막히거나 애매한 것이 있으면 멈추지 말고 가장 자연스러운 쪽으로 정한 뒤, 검토 md 맨 아래 "정한 것"에 한 줄씩 적는다.
