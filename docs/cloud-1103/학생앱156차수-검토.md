# 학생앱 156차수 준비본 · 토익 3차

## 오답만 복습
전에는: 틀린 문제가 새 문제와 섞여 나왔어요.
지금은: 마지막에 틀린 문제만 최대 5개씩 골라 풀 수 있어요. 다시 맞히면 복습 목록에서 빠져요.
확인법: 원장 토익 → 파트5 → 오답만 복습을 누르세요. 유형을 먼저 고르면 그 유형의 오답만 나와요.

## 유형별 정답률
전에는: 푼 문제 수와 남은 오답 수만 볼 수 있었어요.
지금은: 여섯 유형의 정답률·풀이 횟수·남은 오답을 볼 수 있어요. 복습을 포함한 모든 풀이 횟수로 계산하고, 기록이 없으면 기록 없음으로 표시해요.
확인법: 파트5 아래 유형별 정답률을 보세요. 유형을 누르면 그 유형이 선택돼요.

## 풀이와 저장
전에는: 풀이 도중 목록으로 가는 버튼이 없었어요.
지금은: 목록으로 돌아갈 수 있고, 이미 기록한 답은 남아요. 기록 실패는 다시 답을 누를 수 있게 안내해요.
확인법: 한 문제를 푼 다음 목록으로 돌아가세요. 정답률과 오답 개수가 갱신돼요.

## 검증
계산 검사 8개, 브라우저 검사 12개, 앱 빌드가 통과했어요. 휴대폰과 PC 화면을 확인했어요. 검증용 계정과 문제로 확인했으며 실제 학습 기록은 수정하지 않았어요.

## 정한 것
- 정답률은 정답 횟수 ÷ 모든 풀이 횟수이며 반올림해 표시해요.
- 남은 오답은 마지막 답이 틀린 문제예요. 과거 오답 횟수는 지우지 않아요.
- 기존 원장 전용 파트5 접근 범위를 유지해요.
- 3차 준비본만 보존했어요. 실제 서비스 배포는 8차에 해요.
- 다음 차수에는 LC·RC 정답 자료 준비를 진행해요.
