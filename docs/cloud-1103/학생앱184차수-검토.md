# 학생앱 184차수 검토 — 마스터 홈 = 원장 화면(통합) + 학생 이름 검색 (2026-11-19)

원장 결정(11-19): 마스터 홈과 원장 링크를 합친다. 둘 다 문은 남기고, 어느 문으로 들어와도 같은 원장 화면이 뜨게. 학생 탭은 날짜별 명단 + 이름 검색 둘 다.

## 바꾼 것

### 1. 마스터로 들어와도 원장 화면
- `?master=1`(이름 + 뒷 4자리 본인 확인)로 들어오면 예전 마스터 홈(탭 4개) 대신 **원장 화면**(홈·캘린더·단어장·강의·학생·토익, 선생님 출근 기록)이 뜬다.
- 마스터 열쇠는 전처럼 주소창에 안 나온다. 주소는 `?master=1` 그대로.
- 원장 링크(`?tid=admin&tk=…`)도 그대로 된다. 두 문의 화면·기록(단어장 진도, 토익 기록)이 같다.
- 마스터로 학생 화면을 열 때는 예전 마스터 홈과 같은 길로 연다(위에 "👑 마스터" 띠, [마스터 홈] 단추로 원장 화면에 돌아옴).
- **서버가 이 길을 모르면(11-19판 4 이전 워커) 예전 마스터 홈이 그대로 뜬다.** 그래서 앱을 먼저 올려도 원장님이 막히지 않는다.
- 파일: `src/core/auth.jsx`, `src/App.jsx`, `src/screens/teacher/useTeacherActions.jsx`, `src/screens/toeic/useOwnerToeic.jsx`
- 서버(워커 사본 4판에 이미 들어 있음): 원장 문이 `tid=admin` + 마스터 열쇠를 원장으로 받는다.

### 2. 학생 탭에 이름 검색(원장)
- 원장 화면의 학생 탭 맨 위에 "학생 이름 검색 (전체 학생)". 글자를 넣으면 날짜별 명단 대신 찾은 학생이 나오고, 지우면 날짜별 명단으로 돌아온다.
- 선생님 화면에는 검색 칸이 없다(전과 같음).
- 파일: `src/screens/teacher/TeacherStudentsTab.jsx`, `TeacherHome.jsx`

### 3. 같이 고친 것 — 학생을 누르면 홈 화면까지 넘어가던 것
- 학생 이름을 누르면 새 창에 학생 화면이 뜨는데, **원래 창도 같이 학생 화면으로 넘어가고 있었다**(새 창을 여는 방식 때문에 브라우저가 "못 열었다"고 답했음). 이번에 확인하다 발견.
- 이제 새 창이 열리면 원래 창은 그대로 둔다. 새 창이 정말 막힌 폰에서만 원래 창에서 연다.
- 선생님·원장 모두 해당.
- 파일: `src/screens/teacher/useTeacherActions.jsx`

## 확인한 것 (가짜 서버를 붙여 폰 크기 화면으로 눌러 봄)
| 경우 | 결과 |
|---|---|
| 마스터로 들어옴 + 새 서버 | 원장 화면(탭 6개), 주소는 `?master=1`, 토익 탭 저장 안내 없음 |
| 마스터로 들어옴 + 옛 서버(403) | 예전 마스터 홈이 뜸 |
| 원장 링크 | 전과 같은 원장 화면 |
| 학생 탭 이름 검색 | 이름에 그 글자가 든 학생만 나옴 |
| 마스터에서 학생 열기 | `?id=…&t=학생열쇠&master=1`로 새 창, 원래 창은 원장 화면 그대로 |
| 원장 링크에서 학생 열기 | `?tid=admin&tk=…&id=…`로 새 창, 원래 창 그대로 |

- 빌드 성공.

## 아직 못 본 것
- 진짜 서버와 붙여 본 것이 아니다. 특히 마스터로 연 학생 화면이 실제로 열리는지(학생 열쇠를 마스터 목록에서 받아 붙이는 부분).
- 그만둔 학생: 이름 검색은 지금 등록된 학생 명단에서 찾는다. 예전 마스터 홈도 재원생만 보여 줬으므로 달라진 것은 없다.
- 예전 마스터 홈 화면 파일은 되돌아갈 길로 남겨 뒀다(모양은 옛날 그대로).

## 쉬운 요약
마스터로 들어오든 원장 링크로 들어오든 같은 원장 화면이 뜹니다. 학생 탭에서 이름으로 전체 학생을 찾을 수 있고, 학생을 눌러도 원래 창은 그대로 남습니다.
