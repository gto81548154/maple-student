# 학생앱 157차수 준비본 · 토익 4차

## LC·RC 정답 자료
전에는: 앱에서 자동으로 채점할 전체 정답 자료가 준비되어 있지 않았어요.
지금은: MYBOX 해설 원본에서 1~4권, LC·RC 각 10회씩 총 80회차·8,000문항의 정답 후보를 모았어요. 아직 원문 대조 전인 초안이에요.
확인법: 보존한 정답 초안과 회차별 출처 목록을 볼 수 있어요. 화면의 자동채점은 6차에 연결해요.

## 잘못된 정답 자료 차단
전에는: 새 자동채점 자료를 점검하는 도구가 없었어요.
지금은: 회차 중복, 100개 미달, 틀린 문항 번호, 허용하지 않는 보기, 빠진 원본 정보와 대조 기록을 걸러요. 검토가 끝나지 않은 초안은 채점에 사용할 수 없어요.
확인법: 초안 검사에서는 80회차 구조가 통과하고, 채점용 검사에서는 원문 대조 전이라 차단돼요.

## 검증과 정한 것
- 검사 9개와 앱 빌드가 통과했어요.
- 정답 후보는 8,000개 모두 채웠지만, 정확한 정답으로 확정한 것은 아직 없어요.
- 문자 판독에 주의할 1,192곳을 표시했어요. 5차에는 이곳을 우선 확인하고 전체 정답을 원문과 대조해요.
- 정답 자료는 앱 공개 파일에 넣지 않았어요. 기존 원장 전용 접근에 연결하는 일은 6차에 해요.
- 기존 앱 화면과 학습 기록은 그대로예요. 배포는 8차에 진행해요.
