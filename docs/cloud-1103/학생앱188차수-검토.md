# 학생앱 188차수 검토 — 친구 소개 신청: "누구 정보를 적는지" 헷갈리지 않게 (2026-11-25)

원장 말(11-25): 친구 소개 신청에서 친구 것을 적어야 하는지, 내 것을 적어야 하는지 헷갈린다.

## 바꾼 것

### 1. 소개하는 사람(나)을 화면에 보여 줌
- 전에는: 칸이 "친구 이름 / 학교·학년 / 친구 또는 부모님 연락처"만 있어서, 내 정보를 적어야 하는지 친구 정보를 적어야 하는지 알기 어려웠다.
- 지금은: 칸 위에 파란 상자로 "소개하는 사람 · 박서연 (나)"가 나오고, "내 정보는 자동으로 들어가요. 따로 적지 않아도 돼요."라고 적혀 있다. 그 아래에 "👇 소개할 친구 정보를 적어 주세요"가 굵게 나온다.
- 확인법: 더보기 → 장학금·친구 소개 → 친구 소개를 누른다.

### 2. 칸 이름을 전부 "친구"로 맞춤
- 전에는: "학교 · 학년", "친구 또는 부모님 연락처" — 누구의 학교, 누구의 부모님인지 애매했다.
- 지금은: "친구 이름", "친구 학교 · 학년", "친구 연락처 (친구 또는 친구 부모님 번호)". 연락처 칸 아래에 "내 번호가 아니라 친구 쪽 번호를 적어 주세요. 학원에서 이 번호로 연락드려요."가 나온다. 빈칸 안내 글도 "친구 이름 (예: 김마플)", "친구 학교"로 바꿨다.
- 확인법: 같은 화면에서 칸 이름과 빈칸 안내 글을 본다.

### 3. 보내기 전에 한 줄로 다시 보여 줌
- 전에는: 다 적어도 누가 누구를 소개하는지 따로 보여 주지 않았다.
- 지금은: 친구 이름과 연락처를 다 적으면 신청 단추 바로 위에 초록 줄로 "박서연(나) → 노해민 친구를 소개해요"가 나온다.
- 확인법: 친구 이름·연락처를 적어 본다 → 초록 줄이 뜬다.

### 4. 내 이름을 친구 칸에 적으면 막음
- 전에는: 친구 이름 칸에 내 이름을 적어도 그대로 신청됐다.
- 지금은: 내 이름을 적으면 "내 이름이 아니라 소개할 친구 이름을 적어 주세요"가 뜨고 신청 단추가 눌리지 않는다.
- 확인법: 친구 이름 칸에 내 이름, 연락처에 아무 번호를 적어 본다 → 빨간 안내가 뜨고 단추가 흐려진다.

## 제가 미리 확인한 것
- 가짜 서버로 화면을 띄워 폰 폭(390)에서 봤다: 파란 상자·안내 줄·초록 줄이 꺾이지 않고 잘 보인다.
- 내 이름을 적으면 막히고, 친구 이름으로 바꾸면 신청이 되고, 서버로 가는 내용(친구 이름·학교·학년·연락처)은 전과 똑같다.
- 앱 빌드 통과.

## 확인하지 못한 것
- 진짜 학생 계정으로 실제 신청(가짜 서버로만 해 봤다). 서버로 보내는 모양은 안 바뀌었으니 원장앱·워커는 고칠 것 없다.
