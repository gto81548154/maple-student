# 학생앱 181차수 검토 — 출근 기록 + 단원 바로 들어가기(학생도) (2026-11-19)

원장 결정(11-19): ① 단원 바로 들어가기를 학생에게도 ② 선생님이 [출근] 단추를 눌러 출근을 직접 적게 ③ 탭 아이콘·설치 아이콘을 학생용과 같게(합치기).

## 바꾼 것

### 1. 단원 바로 들어가기 — 학생에게도
- 180차수에서 선생님·원장에게만 넣었던 것을 학생 단어장에도 적용.
- 단원을 누르면 "어떻게 공부할까요?" 창 → 방식을 고르면 시작. 여러 단원은 [선택] → [전체 선택] · [선택 해제] · [닫기].
- 숙제 카드로 들어와 범위가 미리 체크돼 있으면 전처럼 체크 방식(아래 방식 카드 + 시작 단추)으로 열린다. 숙제 TEST 길은 건드리지 않았다.
- 파일: `public/voca.html`

### 2. 출근 기록
- 선생님 홈 맨 위와 캘린더(오늘을 골랐을 때)에 **오늘 출근** 칸: [출근]을 누르면 그 시각이 적힌다. 잘못 눌렀으면 오늘 것만 [취소].
- 시각과 날짜는 서버가 정한다(폰 시계를 바꿔도 소용없음). 지난 날은 못 적고 못 고친다. 하루에 한 번, 처음 누른 시각이 남는다.
- 캘린더의 그 달 근무일 모음에 날짜마다 "✓ 17:52" 표시, 위에 "출근 기록 N일". 처음 출근을 적은 날 뒤의 근무일인데 기록이 없으면 "기록 없음"(그 전 날짜에는 안 띄운다).
- 원장 캘린더: 고른 날에 출근을 적은 선생님과 시각이 나온다. 원장 화면에는 [출근] 단추가 없다.
- 서버가 열어 줄 때만(`home.checkin`) 보인다 — 워커를 올리기 전에는 아무것도 달라지지 않는다.
- 파일: `src/screens/teacher/TeacherCheckin.jsx`(새 파일), `TeacherCalTab.jsx`, `TeacherHomeTab.jsx`, `useTeacherActions.jsx`, `TeacherHome.jsx`
- 서버(워커 사본, 저장소에는 없음): `POST /teacher/checkin`, 저장 키 `staffcheckin3:{계정id}`(사람마다 따로), 백업 목록에 추가, 선생님 홈 응답에 내 기록·(원장에게) 전 직원 기록.

### 3. 아이콘·설치본을 학생앱과 같게
- 선생님 화면의 탭 아이콘·아이폰 홈 화면 아이콘을 학생앱 그림으로(180차수), 아이폰 홈 화면 이름도 "마플쌤" → "마플영어".
- 알게 된 것: `index.html`에 고정 manifest 줄이 있어서, 앱이 실행 중에 넣으려던 선생님용 manifest는 원래부터 쓰이지 않고 있었다. 설치 아이콘은 그 페이지의 아이콘(위에서 바꾼 것)을 따라간다.
- 이미 깔아 둔 초록 아이콘은 그대로 남는다. 지우고 다시 깔아야 바뀐다.
- 파일: `src/core/pwa.jsx`

| 학생 단어장 | 누르면 방식 창, [선택] 방식도 됨 (180차수 확인과 같은 길) |

- 빌드 성공.

## 아직 못 본 것
- 진짜 서버와 붙여 본 것이 아니다.
- 학생이 숙제 카드로 들어오는 길(범위가 미리 체크됨)은 코드로만 확인했다(체크가 있으면 선택 방식으로 연다).
- 퇴근 기록, 원장이 기록을 고치는 기능, 달별 모아 보기(엑셀 등)는 없다.

## 쉬운 요약
선생님이 [출근] 단추로 출근 시각을 남기고, 원장님은 캘린더에서 날짜별로 봅니다. 단원을 누르면 바로 들어가는 방식은 학생에게도 적용했습니다.
