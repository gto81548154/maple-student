# 학생앱 174차수 검토 — 학교·날짜 읽기 바로잡기 (2026-11-12)

## 고친 것

### 1. "○○중앙고"를 "○○중"으로 잘못 읽던 것
- 전에는: 학교 글자를 다 붙인 뒤 처음 나오는 "중·고"에서 끊었습니다. "광주중앙고"가 "광주중"이 돼서, 그 학생에게 광주중 시험 D-day와 시험 범위가 보일 수 있었습니다.
- 이제는: 띄어쓰기로 나눈 낱말마다 보고, "중·고"로 끝나는 온전한 학교 이름을 고릅니다.
- 시험 이름에서 학교를 뽑을 때도 같은 규칙을 씁니다("윤슬중기말고사" → 윤슬중, "광주중앙고 기말" → 광주중앙고).
- 파일: `src/domain/dday.jsx`

### 2. 이름에 "고"가 든 중학교를 고등학교로 보던 것
- "고덕중", "고양중"처럼 학년이 "2", "3학년"으로만 적힌 학생이 고등학생으로 잡혀 모의고사 D-day가 보일 수 있었습니다.
- 이제는: 학교 이름의 끝 글자(중/고)로 봅니다.
- 파일: `src/domain/dday.jsx`

### 3. 숙제에 적은 날짜·쪽수가 단어 범위로 읽히던 것
- "단어-워마 수능 25 26 (11/14까지)" → 전에는 DAY 11·14·25·26, 이제는 DAY 25·26.
- "11/14(토)", "11월 14일까지", "14일까지", "p.30", "30p"를 범위에서 뺍니다.
- 그냥 "25/26"은 단원 두 개일 수 있어 그대로 둡니다.
- 파일: `src/domain/voca.jsx`

### 4. 틀린 단어 기한 D-day가 하루 많게 나오던 것
- "11/15(일)까지"인데 목요일에 D-4로 나왔습니다. 이제 D-3입니다. 일요일 당일은 "D-Day"로 나옵니다.
- 파일: `src/domain/vocabTest.jsx`, 표시하는 곳 3군데(홈, 안내 카드, 더보기)

### 5. 장학금 신청서의 학기 기본값
- 1~2월 → 작년 2학기 / 3~8월 → 올해 1학기 / 9~12월 → 올해 2학기.
- 전에는 늘 목록의 마지막 학기여서, 7월에 1학기 기말로 신청할 때 2학기가 골라져 있었습니다.
- 파일: `src/screens/more/RewardScreen.jsx`

## 확인한 것 (계산 함수를 직접 돌림)
- 학교 이름 26가지 모두 기대한 대로. 예: 광주중앙고1 → 광주중앙고, 윤슬중2학년 → 윤슬중, 하남 고등학교 → 하남고, 고덕중 → 고덕중, 박상우-남한고1 → 남한고, 이름 "이중수" → 학교 아님.
- 중·고 구분 5가지 맞음.
- 단어 범위 6가지 맞음.
- 오늘(11/12 목) 기준 "11/15(일)", D-3.
- 빌드 성공.

## 아직 못 본 것
- **진짜 학생 명단으로 돌려 본 것이 아닙니다.** 학교 이름이 특이하게 적힌 학생이 있으면 결과가 달라질 수 있습니다. 배포 뒤, 시험 D-day가 사라지거나 엉뚱한 시험이 보이는 학생이 없는지 봐 주세요.
- 장학금 신청 화면은 실제로 열어 보지 않았습니다(날짜 계산만 바꿈).

## 알아 두실 것
- "○○중앙고" 학생의 시험 범위 찾기 열쇠가 "광주중1" → "광주중앙고1"처럼 바뀝니다. 원장앱에서 시험 범위를 "광주중앙고1"로 올려 두셨다면 이제 제대로 보입니다.
- 대부분의 학교(윤슬중, 하남고, 남한고 등)는 전과 똑같이 읽습니다.

## 쉬운 요약
학교 이름과 날짜를 잘못 읽던 다섯 군데를 고쳤습니다. 아직 배포는 안 했습니다.
