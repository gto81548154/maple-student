# 학생앱 152차수 검토 — 🎤 파닉스 숙제 (2026-11-05)

원장 요청(11-05): 원장앱(309차수)에서 낸 파닉스 숙제(단어 몇 개)를 학생이 단어마다 녹음해서 보내고, 선생님은 원장앱에서 듣는 것. 학생앱은 메뉴 "🎤 파닉스", 숙제 안(단어별 녹음), 홈 단추 세 가지를 만들었어요. 모든 요청에 지금처럼 학생 번호와 열쇠를 붙여요.

화면 캡처: `docs/cloud-1103/152차수-홈.png`(홈 단추) · `docs/cloud-1103/152차수-파닉스-숙제안.png`(숙제 안)

## 1. 더보기에 "🎤 파닉스" 메뉴 — "녹음 제출"은 이 안으로
- 전에는: 더보기 → 학습 묶음에 "🎤 녹음 제출 — 읽고 녹음해서 보내기" 줄이 있었어요.
- 지금은: 그 자리에 "🎤 파닉스" 줄이 있어요. 설명은 안 끝난 숙제가 있으면 빨간 글로 "안 끝난 숙제 2개 · 11/7까지", 없으면 "단어 녹음 숙제 · 자유 녹음"(숙제를 다 보냈으면 "숙제 다 보냈어요 · 자유 녹음"). 옛 "녹음 제출" 화면은 파닉스 화면 맨 아래 "자유 녹음" 칸으로 그대로 들어갔어요(읽은 내용 칸 · 녹음 시작 · 내가 보낸 녹음 전부 그대로). 옛 "녹음 제출" 바로가기 주소로 들어와도 파닉스 화면이 열려요.
- 확인법: 아래 탭 "더보기" → "파닉스"를 눌러 보세요. 맨 아래로 내리면 "자유 녹음"이 있어요.

## 2. 숙제 목록(마감 가까운 것 먼저)
- 전에는: 없던 화면이에요.
- 지금은: 숙제 카드가 마감 가까운 순서로 서요. 카드마다 "11/7(토)까지 · 워드마스터 Basic DAY 3 · 단어 5개 · 녹음 3/5"와 원장 메모 한 줄(있으면 💬). 다 보낸 숙제는 초록 "✓ 다 보냈어요", 마감이 지났는데 덜 보낸 숙제는 빨간 "마감 지남"(테두리도 연한 빨강). 마감 뒤 7일이 지난 숙제는 워커가 안 주니까 앱은 따로 지우지 않아요. 숙제가 하나도 없으면 "지금 파닉스 숙제가 없어요", 워커가 아직 없거나 연결이 안 되면 "숙제 목록을 아직 불러올 수 없어요"와 [다시 받기].
- 확인법: 더보기 → 파닉스. 원장앱에서 숙제를 낸 학생으로 열어 보세요.

## 3. 숙제 안 — 단어 한 줄씩 녹음
- 전에는: 없던 화면이에요.
- 지금은: 카드를 누르면 숙제 안으로 들어가요(맨 위 "‹ 숙제 목록"). 위 카드에 숙제 이름·단어 수·마감, 선생님 메모(노란 칸), 그 아래 띠에 "2개 남음 · 11/7(토)까지 · 녹음 3/5"와 막대. 단어는 한 줄씩 `address` · `주소; 연설` · 오른쪽 [🎙 녹음]. 보낸 단어는 [▶ 0:04](누르면 들리고, 다시 누르면 멈춤) · [다시 녹음]으로 바뀌고, 줄 아래 "보냄", 선생님이 들었으면 "선생님 확인 ✓", 메모가 있으면 "💬 메모" 한 줄(녹음 제출 목록과 같은 모양). 푸시는 안 와요.
- 확인법: 숙제 카드를 눌러 들어가 보세요. 보낸 단어의 ▶를 눌러 들어 보세요(일주일 동안 들을 수 있어요).

## 4. 녹음 → 미리 듣기 → 보내기 (한 단어 최대 20초)
- 전에는: 없던 기능이에요.
- 지금은: [🎙 녹음]을 누르면 폰이 마이크 허용을 물어요(145차수 녹음 부품 그대로 — 아이폰은 mp4로 녹음돼요). 그 줄이 열리면서 빨간 점과 "녹음 중 0:03 / 0:20", 빨간 막대, [■ 정지]. 20초가 되면 저절로 멈춰요. 멈추면 "녹음 완료 0:05 / 0:05"와 [▶ 미리 듣기] · [↺ 다시] · [취소] · 남색 [보내기]. [보내기]를 누르면 "보내는 중…" → 그 줄이 [▶ 0:05] · [다시 녹음]으로 바뀌고 "보냈어요 ✓"가 2초 떠요. 숙제 숫자("녹음 4/5", "1개 남음")는 보내자마자 바로 고쳐지고, 뒤이어 목록을 한 번 더 받아 서버와 맞춰요. 한 번에 한 단어만 녹음돼요(다른 단어 [🎙 녹음]을 누르면 아직 안 보낸 녹음은 버려져요). 녹음 중에 다른 앱으로 가거나 화면을 나가면 멈추고 버려져요(145차수와 같음).
- 확인법: 단어 하나를 [🎙 녹음] → 몇 초 말하고 [■ 정지] → [▶ 미리 듣기] → [보내기]. 원장앱 수업실 🎤 녹음 패널(또는 파닉스 화면)에 그 단어 녹음이 뜨는지 보세요.

## 5. 다시 녹음(덮어쓰기)과 다 보냈을 때
- 전에는: 없던 기능이에요.
- 지금은: 보낸 단어의 [다시 녹음]을 누르면 새로 녹음하고, [보내기(덮어쓰기)]를 누르면 옛 녹음을 덮어써요(옛 파일은 워커가 지워요). 단어를 전부 보내면 위 띠가 초록 "다 보냈어요 🎉"로 바뀌고 목록 카드에도 "✓ 다 보냈어요"가 붙어요.
- 확인법: 보낸 단어에서 [다시 녹음] → [보내기(덮어쓰기)]. 마지막 단어를 보내면 띠가 초록으로 바뀌는지 보세요.

## 6. 마감이 지난 숙제
- 전에는: 해당 없음.
- 지금은: 마감이 지났는데 덜 보냈으면 띠가 빨간 "마감 지남 · 1개 남음 / 11/8까지는 보낼 수 있어요"로 바뀌고, 그래도 마감 뒤 7일까지는 보낼 수 있어요. 7일이 지나면 [🎙 녹음]·[다시 녹음]이 꺼지고 "마감이 지나서 이제 보낼 수 없어요"가 떠요(보통은 워커가 아예 안 줘서 목록에서 사라져요).
- 확인법: 마감이 지난 숙제를 열어 보세요.

## 7. 홈 "지금 폰으로 할 공부"에 파닉스 단추
- 전에는: 홈 ④ 카드에 단어 공부 · 강의 · 오답 복습만 있었어요.
- 지금은: 안 끝난 파닉스 숙제(덜 보낸 것, 마감 뒤 7일 안)가 있으면 카드 맨 위에 단추 **[🎤 파닉스 숙제 5개 · 11/7까지] [녹음하기]**, 아래 작은 빨간 글 "2개 남음"(마감이 지났으면 "2개 남음 · 마감 지남"). 숙제가 2개 이상이면 마감 가까운 것 하나만 단추로 쓰고 "외 1개"를 붙여요. 누르면 그 숙제 안(단어 목록)으로 바로 가요. 안 끝난 숙제가 없으면 단추는 안 보여요. 맨 위 "오늘 할 일 N개 남았어요" 숫자에도 안 끝난 파닉스 숙제 수가 더해져요.
- 확인법: 안 끝난 파닉스 숙제가 있는 학생으로 홈을 열어 보세요. 단추를 누르면 바로 단어 목록이 나와요.

## 8. 알림·앱 카드에서 파닉스로
- 전에는: 푸시 알림을 누르면 앱이 열리기만 했고(홈), 앱 카드의 단추는 아는 화면 이름만 갔어요.
- 지금은: 워커가 알림에 화면 이름을 주면 그 화면으로, 안 줘도 알림 제목에 "파닉스"가 있으면 "🎤 파닉스" 메뉴로 가요(앱이 이미 켜져 있으면 그 화면으로 옮기고, 꺼져 있으면 파닉스 주소로 열어요). 앱 카드의 화면 이름이 파닉스면 그 단추도 "🎤 파닉스" 메뉴로 가요.
- 확인법: 원장앱에서 가는 화면을 "파닉스"로 한 앱 카드를 올리고 학생앱을 켜서 단추를 눌러 보세요. 푸시는 워커가 "🎤 파닉스 숙제 …" 알림을 보낼 때 눌러 보세요.

## 9. 폰 뒤로가기·새로고침
- 전에는: 해당 없음.
- 지금은: 숙제 안에서 폰 뒤로가기 한 번 = 숙제 목록, 한 번 더 = 더보기(또는 홈). "‹ 숙제 목록"을 눌러도 뒤로가기와 같이 칸을 거둬서 뒤로가기를 두 번 누르지 않아도 돼요. 숙제 안에서 새로고침하면 같은 숙제가 다시 열려요.
- 확인법: 숙제 안에서 폰 뒤로가기를 눌러 보세요.

## 끝낼 때 확인한 것
- 설치와 빌드 성공을 확인했어요.
- 가짜 워커(숙제 4개: 마감 지난 것 1/2 보냄 · 다 보낸 것 · 3/5 보낸 것 · 0/3)를 붙인 크롬(가짜 마이크)에서 30가지를 눌러 봤어요: 앱 카드 단추 → 파닉스 · 목록 순서(11/1 → 11/6 → 11/7 → 11/10) · ✓/마감 지남 표시 · 자유 녹음 칸 · 홈 단추 글("🎤 파닉스 숙제 2개 · 11/1까지 외 2개", "1개 남음 · 마감 지남") · 홈 요약 숫자 · 단추 → 숙제 안 · 보낸 단어의 ▶ 0:04 · 다시 녹음 · 선생님 확인 ✓ · 메모 · [🎙 녹음] → "녹음 중 / 0:20" → [■ 정지] → [보내기] → 보낸 값(어느 숙제·몇 번 단어·단어·길이·형식·소리 파일·학생 번호·열쇠) → "다 보냈어요 🎉" · 뒤로가기 → 목록(2/2로 고쳐짐) · ‹ 숙제 목록 뒤 뒤로가기 = 홈 · 더보기 줄 설명 · 알림 메시지 → 파닉스 · 옛 녹음 제출 주소 → 파닉스 · 숙제 안 새로고침 복원 · 숙제 없을 때 홈 단추 숨김 · 워커 404 안내. 브라우저 오류 없음(글꼴 CDN이 막힌 시험 환경의 메시지만).
- 실제 워커(13단계)에는 붙여 보지 못했어요 — 이 저장소에 워커 지시문이 없어서 값 이름은 아래 "정한 것"대로 읽어요. 검토 뒤 고친 것(옛 목록이 와도 방금 보낸 녹음 지키기 · 빠른 두 번 누름 · 200인데 모양이 다른 답 · 지난 날짜 숫자)도 같은 방법으로 다시 확인했어요.

## 정한 것
- 한 단어 최대 20초 · 마감 뒤 7일까지 보임·보낼 수 있음 · 녹음 제출 메뉴는 파닉스 안(맨 아래 "자유 녹음")으로 — 지시문대로.
- 워커 지시문(13단계)은 이 저장소에 없어서, 숙제 목록의 값 이름은 지시문의 보기("단어 5개·녹음 3/5", 단어 번호·단어·뜻, 보낸 녹음의 파일·길이·시각·들었음·메모)대로 읽게 했어요. 이름이 조금 달라도 읽히게 여유를 뒀고, 그래도 안 맞으면 앱 안 한 곳만 고치면 돼요(어디인지는 코드 주석에 적어 뒀어요).
- 단어 녹음은 145차수 녹음 제출과 같은 길로 보내고, 어느 숙제의 몇 번 단어인지만 더 붙여요(읽은 내용 칸에는 단어가 들어가요). 녹음 파일이 2MB를 넘으면 안 보내는 것도 같아요.
- 보낸 뒤 서버 답에 숫자가 없으면 단어 목록을 세어서 "녹음 n/m"을 고쳐요. 보낸 직후 목록을 다시 받을 때 서버가 잠깐 옛 목록을 줘도 방금 보낸 녹음은 폰에 있는 것을 지켜요(되돌아가지 않게).
- 홈 단추의 "안 끝난 숙제" = 덜 보낸 숙제(마감 뒤 7일 안). 다 보낸 숙제는 마감 전이어도 단추에서 빼요. 홈 맨 위 "오늘 할 일 N개" 숫자에는 오늘 날짜를 볼 때만 안 끝난 파닉스 숙제 수를 더해요(지난·다음 날짜 숫자에는 안 더함 — 날짜와 상관없는 숙제라서).
- 선생님·원장이 학생 화면을 보기 전용으로 열었을 때는 홈 단추·더보기 빨간 글을 안 띄우고, 녹음·보내기도 막아요(145차수와 같음).
- 알림을 눌렀을 때 갈 화면은 워커가 화면 이름을 주면 그것, 없으면 제목에 "파닉스"가 있을 때만 파닉스로 짐작해요. 앱이 꺼져 있을 때는 지금처럼 첫 주소로 열어서(145차수 이전부터 같은 동작), 홈 화면에 추가한 앱이 아니면 학생 번호가 없는 첫 화면이 열릴 수 있어요 — 이번엔 안 건드렸어요.
- 숙제 안에서는 "‹ 더보기"를 빼고 "‹ 숙제 목록" 하나만 뒀어요(되돌아가기 단추가 두 줄로 겹치지 않게).
- 워커가 200으로 답했는데 내용이 숙제 목록 모양이 아니면(아직 길이 없을 때 빈 페이지가 오는 경우) "숙제 없음"이 아니라 "불러올 수 없어요"로 보여요.
- 녹음 단추를 아주 빠르게 두 번 누르거나 두 단어를 연달아 누르면 마이크를 한 번만 열어요(두 번 열려 첫 번째가 안 꺼지는 일을 막음 — 자유 녹음에도 같이 적용).
- 원장 결정(11-04)대로 main에 바로 올렸어요(작업 가지에도 같이 올림).
