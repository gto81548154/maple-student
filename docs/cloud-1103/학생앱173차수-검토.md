# 학생앱 173차수 검토 — 채점 바로잡기 (2026-11-12)

틀린 답을 맞다고 하던 것 2개, 맞는 답을 틀리다고 하던 것 2개, 시작이 안 되던 것 1개를 고쳤습니다.

## 고친 것

### 1. 오답 복습: 끝 글자만 다른 "다른 낱말"을 정답으로 치던 것 (원장 결정: 좁게)
- 전에는: 끝 글자(의·적·한·인·다…)를 떼고 비교해서 "성인"과 "성적"이 둘 다 "성"이 됐습니다.
- 이제는: **떼고 남는 글자가 2글자 이상일 때만** 뗍니다. "인"은 어미 목록에서 뺐습니다("한국인"과 "한국의"는 다른 말).
- 파일: `src/domain/vocabAnswer.jsx`

| 정답 | 쓴 답 | 전 | 지금 |
|---|---|---|---|
| 성인 | 성적 | 정답 | 오답 |
| 주의 | 주인 | 정답 | 오답 |
| 원한 | 원인 | 정답 | 오답 |
| 살인 | 살다 | 정답 | 오답 |
| 개인 | 개 | 정답 | 오답 |
| 비정상의 | 비정상적인 | 정답 | 정답(그대로) |
| 중요한 | 중요하다 | 정답 | 정답(그대로) |
| 해결하다 | 해결 | 정답 | 정답(그대로) |

### 2. 오답 복습: 괄호 안 도움말만 써도 정답이던 것
- "(물건을) 사다"에 "물건", "(~을) 제공하다"에 "을"만 써도 맞았습니다.
- 이제는: 괄호 안이 "~"로 시작하거나, 3글자 이상이면서 을·를·에게·에서·으로 로 끝나면 도움말로 보고 정답에 넣지 않습니다.
- "촌락(마을)"의 "마을", "미술가(화가)"의 "화가"처럼 진짜 다른 말은 그대로 정답입니다.
- 파일: `src/domain/vocabAnswer.jsx`

### 3. 단어장: AI 재검토가 맞다고 해도 "오답 유지"로 나오던 것
- 전에는: "한 번도 안 쓴 뜻"일 때만 인정했습니다. 1회독에서 맞힌 단어는 2회독부터 AI가 맞다 해도 늘 오답 유지였고, 하루 30번인 재검토 횟수만 줄었습니다.
- 이제는: 보통 채점과 **같은 규칙**으로 인정합니다(뜻이 하나거나 1·2회독이면 인정, 3회독부터는 앞 회독에서 쓴 뜻만 안 됨).
- 파일: `public/voca.html` (`senseUsable`)

### 4. 단어장: 괄호·대괄호를 풀어 쓴 답을 오답으로 치던 것
- "(영화를) 상영하다" → "영화를 상영하다"도 정답
- "허락[허가]하다" → "허가하다"도 정답
- "~에 대한" → "대한"도 정답
- 파일: `public/voca.html` (`keyForms`, `matchSense`)

### 5. 단어장: [20개씩]을 켜면 "오답만 다시 도전"이 시작 안 되던 것
- 전에는: 방금 틀린 단어가 전부 "이미 본 단어"라서 "이 범위는 다 봤어요" 창만 떴습니다.
- 이제는: "오답만 다시 도전"과 오답 모아 보기에서는 "이미 본 단어 빼기"를 하지 않습니다.
- 파일: `public/voca.html` (`startSession`)

## 확인한 것
- 빌드 성공.
- 오답 복습 채점: 예시 25개(틀려야 하는 것 10개, 계속 맞아야 하는 것 15개) 모두 기대한 대로.
- 단어장 채점: 예시 11개 모두 기대한 대로. AI 재검토 인정 규칙 4가지 경우 맞음.
- [20개씩] + 오답만 다시: 창 없이 바로 시작됨. 보통 시작은 전처럼 "다 봤어요" 창이 뜸.

## 아직 못 본 것
- 진짜 책 자료의 정답 글로 전부 돌려 본 것은 아닙니다(책 자료는 서버에 있음). 대표적인 모양만 확인했습니다.
- AI 재검토는 실제 서버 답을 받아 본 것이 아니라 인정 규칙만 확인했습니다.

## 알아 두실 것 (더 엄격해진 곳)
- "먹다"↔"먹는"처럼 **떼고 나면 한 글자만 남는** 짧은 말은 이제 끝 글자가 달라도 봐주지 않습니다. 정답과 똑같이 써야 합니다. "성인↔성적"을 막으려면 어쩔 수 없는 부분입니다.
- 오답 복습에서 틀리던 학생이 갑자기 더 틀리게 느낄 수 있습니다. 실제로는 다른 낱말을 쓴 경우입니다.

## 쉬운 요약
틀린 답이 통과되던 구멍 두 개를 막고, 맞는 답이 틀리던 것 두 개와 "오답만 다시"가 안 되던 것을 고쳤습니다. 아직 배포는 안 했습니다.
