# 학생앱 177차수 검토 — 원장 토익 저장 (2026-11-12)

원장님만 쓰는 토익 화면의 저장 문제 5개입니다. 학생 화면에는 영향이 없습니다.

## 고친 것

### 1. [막힌 기록 버리기]를 누르면 그 뒤에 넣은 답이 사라지던 것
- 전에는: 버린 옛 답을 "이 기기 보관 답"에 무조건 덮어썼습니다. 막힌 뒤에 새로 넣은 답이 옛 답으로 바뀌었습니다(화면 글은 "사라지지 않아요"였음).
- 이제는: **더 새 답이 없을 때만** 버린 답을 되살립니다. 기기에 새 보관 답이 있거나, 같은 회차의 더 나중 저장이 대기 중이면 건드리지 않습니다.
- 파일: `src/screens/toeic/useOwnerToeic.jsx`, `src/domain/toeicSync.mjs`

### 2. LC 회차를 빠르게 넘기면 "지난번 20:00까지 들었어요"가 0:00이 되던 것
- 음원 정보를 다 읽기 전에 다른 회차를 누르면 0초가 저장됐습니다. 이제는 음원을 읽고 지난번 위치로 옮긴 뒤에만 위치를 저장합니다.
- 파일: `src/screens/toeic/OwnerToeicPanel.jsx`

### 3. 열려 있는 회차를 또 누르면 재생 막대가 고장 나던 것
- 이제는 이미 열린 회차를 다시 눌러도 아무것도 바뀌지 않습니다.
- 파일: `src/screens/toeic/OwnerToeicPanel.jsx`

### 4. 서버가 실은 저장해 놓고 오류로 답한 기록을 버리면, 다음 기록이 조용히 사라지던 것
- 이제는: 버리기 전에 서버 기록을 한 번 다시 봅니다. 이미 저장돼 있었으면 버릴 것 없이 대기에서만 빠지고, 뒤 기록은 제 번호로 저장됩니다.
- 파일: `src/domain/toeicSync.mjs`

### 5. 토익 창을 두 개 띄우면 듣던 위치가 뒤로 돌아가던 것
- 맨 앞 대기 기록에는 새 위치를 합치지 않습니다(다른 창이 보내는 중일 수 있어서). 대신 대기 기록이 한 개 더 생길 수 있습니다.
- 파일: `src/domain/toeicSync.mjs`

## 확인한 것 (저장 대기열을 가짜 서버로 직접 돌림)
| 경우 | 결과 |
|---|---|
| 서버가 저장해 놓고 502 답 → 버리기 | 뒤의 Part 5 기록이 서버에 들어감, 대기 0 (서버 종류 두 가지 모두) |
| 서버가 정말 거절(400) → 버리기 | 버린 답을 돌려줌, 뒤 기록은 저장됨 |
| 막힌 답 A 뒤에 더 새 답 B 대기 중 → 버리기 | "더 새 답 있음" 표시, 서버와 화면 모두 B |
| 창 두 개: 한 창이 100초를 보내는 중 다른 창이 900초 | 서버에 900초가 남음 |
| 같은 창에서 위치 5번 | 대기 2개 이하, 마지막 위치 50초 |

- 빌드 성공.
