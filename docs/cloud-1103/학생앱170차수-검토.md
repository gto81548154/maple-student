# 학생앱 170차수 검토 — 새 팝업 [단어 리그] 탭을 진짜 자료로 (2026-11-12)

## 무엇을 바꿨나요
- 워커가 학생 묶음에 넣어 주는 `league`(단어 리그 자료 약속 (2))를 받아서, 새 팝업의 **[단어 리그] 탭**에 그립니다.
- 보이는 것: 제목·기간, 상품, 시상대 1~3등(가린 이름·점수), 내 순위와 "다음 등수까지 몇 번", 완주상 막대, [단어 공부 하러 가기].
- `league`가 없거나 null이거나 모양이 이상하면 **지금처럼 "준비하고 있어요" 안내**가 그대로 나옵니다. 워커가 아직 안 올라와 있어도 화면이 깨지지 않습니다.
- 상태별: 시작 전(`upcoming`) = "곧 시작해요 · ○월 ○일에 시작해요" / 진행 중(`running`) = 순위 / 끝남(`ended`) = "최종 순위".
- 선생님·원장 보기(`me`가 null)에서는 "내 순위" 칸이 안 나옵니다.
- 색은 파스텔 파랑·민트만 썼습니다. 주황·이모지는 안 썼습니다.
- 새 팝업은 여전히 **앱을 켤 때 저절로 뜨지 않습니다.** 더보기 → "안 쓰는 기능"(원장·선생님만 보임)에서 눌러야 열립니다.

## 고친 파일
- `src/core/bundle.jsx` — 워커 답에서 `league` 칸을 꺼냄(없으면 null).
- `src/state/useBundleState.jsx` · `src/state/useBundleLoader.jsx` — `league` 상태 추가, 묶음에서 받기.
- `src/App.jsx` — `LabPopup`에 `league` 넘기기.
- `src/ui/LabPopup.jsx` — 단어 리그 탭 그리기(`normalizeLeague`, `LeagueBody`).
- `tests/browser/labPopup-harness/main.jsx` — 가짜 리그 자료(`?league=running|upcoming|ended|first|zero|staff|bad`).
- `src/core/config.jsx` — 버전 글씨 170차수.

## 확인한 것 (가짜 자료, 폰 너비 390)
- 빌드 성공.
- 8가지 경우 모두 오류 없이 뜨고 옆으로 넘치지 않음: 진행 중 / 시작 전 / 끝남 / 내가 1등 / 아무도 점수 없음 / 선생님 보기 / 이상한 자료 / 자료 없음.
- [단어 공부 하러 가기]를 누르면 단어 탭으로 감.
- 그림: `170차수-단어리그.png` (진행 중).

## 아직 못 본 것
- **진짜 워커 자료로는 못 봤습니다.** 워커가 아직 `league`를 안 주기 때문입니다. 워커가 올라오면 원장 링크로 한 번 열어 봐야 합니다.
- 실제 앱(원장·학생 링크)에서 "안 쓰는 기능" 칸이 보이고 숨는 것도 아직 못 봤습니다.
- 내용이 길면 [단어 공부 하러 가기] 단추는 팝업 안에서 아래로 내려야 보입니다.

## 약속(자료 모양)은 그대로
- 약속 (2)를 하나도 안 바꿨습니다. 워커 채팅에 전할 것 없습니다.

## 쉬운 요약
단어 리그 탭이 순위를 보여 줄 준비를 마쳤습니다. 워커가 자료를 주기 전까지는 지금처럼 "준비 중"으로 보입니다. 아직 배포는 안 했습니다.
