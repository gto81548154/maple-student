# 학생앱 185차수 검토 — 학생 토익(원장이 켠 학생만) (2026-11-19)

원장 결정(11-19): 학생에게도 선생님과 똑같은 토익을 쓰게 한다. 원장이 켜 준 학생만, 여러 명 가능, 자리는 더보기.

## 바꾼 것

### 1. 원장: 학생마다 토익 켜고 끄기
- 원장 화면 → 학생 탭의 학생 줄 오른쪽에 [토익 끔] / [토익 켬] 단추(날짜별 명단, 이름 검색 결과 둘 다).
- 누르면 확인창 뒤에 바뀐다. 끄면 그 학생 앱에서 토익이 사라질 뿐 **기록은 지워지지 않고**, 다시 켜면 이어진다.
- 선생님 화면에는 이 단추가 없다. 서버도 원장 링크(또는 마스터)만 받는다.
- 파일: `src/screens/teacher/TeacherStudentsTab.jsx`, `useTeacherActions.jsx`, `TeacherHome.jsx`

### 2. 학생: 더보기에 "토익"
- 켜 준 학생의 더보기 → 학습 칸에 "🎧 토익"이 생긴다. 들어가면 선생님 토익과 같은 화면(LC·RC 회차, 음원·문제지·해설, 답 입력·채점, 파트5 5문제).
- 기록은 학생마다 따로 저장된다(서버 칸 `toeic3:s_{학생id}`). 선생님·원장·다른 학생과 섞이지 않는다.
- 켜져 있는지는 앱을 열 때 서버에 가볍게 묻고 5분 동안 기억한다. 그래서 **원장이 켠 뒤 학생 화면에 나타나기까지 최대 5분**쯤 걸릴 수 있다(앱을 다시 열면 바로).
- 꺼진 학생이 주소(`#toeic`)로 직접 들어오면 "토익이 켜져 있지 않아요" 안내만 나온다. 서버도 기록·파일을 열어 주지 않는다.
- 원장·선생님이 학생 화면을 열어 본 때(보기 전용)에는 토익이 안 나온다 — 학생 기록에 손대지 않게.
- 파일: `src/core/toeicAccess.jsx`(새 파일), `src/screens/toeic/StudentToeic.jsx`(새 파일), `useOwnerToeic.jsx`, `OwnerToeicP5.jsx`, `src/domain/toeic.jsx`, `src/state/computeMoreView.jsx`, `makeTabNav.jsx`, `src/App.jsx`

### 3. 서버(워커 사본 5판, 저장소에는 없음)
- `GET·POST /student/toeic`(학생 열쇠 + 켜진 학생만), `POST /teacher/toeic-student`(원장만), 토익 파일을 켜진 학생의 열쇠로 열기, 켠 학생 목록 `toeic_students3`(백업 목록에 추가), 원장 홈 응답에 목록.
- 학생 열쇠가 정확히 맞아야 한다. 열쇠가 아직 없는 학생은 켜 줘도 못 쓴다(아무 글자나 통과하는 일이 없게).

## 아직 못 본 것
- 진짜 서버와 붙여 본 것이 아니다.
- 자동 채점은 전과 같이 정답 80회차 파일이 서버에 있어야 된다(없으면 채점만 거절).

## 쉬운 요약
원장님이 학생 탭에서 [토익 켬]으로 바꾼 학생은 더보기에 토익이 생기고, 선생님과 같은 화면을 자기 기록으로 씁니다.
