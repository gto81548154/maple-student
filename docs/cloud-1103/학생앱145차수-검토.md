## 끝낼 때 확인한 것
- 설치와 빌드 성공을 확인했어요.
- 가짜 학원 서버(학생 자료 + 녹음 보내기/목록/듣기)와 가짜 마이크를 붙인 크롬에서 실제로 눌러 봤어요: 더보기 → 녹음 제출 열림(주소 #record), 녹음 시작 → "0:02 / 1:30" 표시 → 정지 → 들어보기(끝나면 저절로 멈춤) → 다시 녹음 → 제출 → "제출했어요 ✓" 2초 → 목록 맨 위에 추가·칸 비워짐. 두 번째 보낸 뒤 목록 2개, "선생님 확인 ✓"·메모 줄, [▶] 한 번에 하나만 재생.
- 90초 자동 정지: 시계를 앞당겨서 1:30이 되면 저절로 멈추고 "1:30 / 1:30"으로 제출 단추가 나오는 것을 확인했어요.
- 서버가 녹음 길을 모를 때(404): 목록은 "아직 불러올 수 없어요", 제출은 "지금은 제출할 수 없어요" 안내만 뜨고 앱은 계속 돼요. 마이크 거부 → "마이크 사용을 허용해 주세요" + [다시 시도]. 녹음 중 화면 가림 → 멈추고 버림 안내.
- 아이폰 사파리: 형식을 "webm(opus) → webm → mp4 → ogg" 순서로 되는 첫 것을 고르는 코드가 들어 있어서 사파리에서는 audio/mp4가 골라져요. 실기기 확인은 원장이 해 주세요.
- 보내는 파일 모양: 크롬에서 2초 녹음이 약 3KB(32kbps)였어요. 90초면 약 400KB로 2MB 한도 안이에요.

- 녹음 길이(초)는 녹음 시작부터 멈출 때까지 잰 시간을 반올림하고 1~90 사이로 맞춰요. 1초도 안 되게 눌렀다 떼도 1초로 보내요.

- 목록의 날짜 묶음 제목은 오늘이면 "오늘 · 11월 4일 (수)", 아니면 "11월 3일 (화)"로 했어요. 줄의 시각은 보낸 시각(at)에서 시:분만 보여요.
- 읽은 내용을 안 적은 녹음은 목록에 흐린 글씨로 "읽은 내용 없음"이라고 보여요.
