# 토익 종합 검토와 수정

전에는: 답 여러 개를 아주 빠르게 누르면 앞선 답이 빠질 수 있었어요.
지금은: 입력한 순서대로 답을 보관하고, 두 창에서 서로 다른 문항을 바꿔도 함께 유지해요.
확인법: 토익 회차에서 여러 답을 빠르게 누른 뒤 다시 열어 확인해 주세요.

전에는: 저장된 답 불러오기를 눌러도 다른 기기에서 저장한 최신 답이 보이지 않을 수 있었어요.
지금은: 서버에 저장된 최신 답을 불러와요. 연결이 안 되거나 다른 창에서 답을 바꾸면 지금 답을 지우지 않아요.
확인법: 다른 기기에서 답 저장을 누른 뒤 원래 기기에서 저장된 답 불러오기를 눌러 주세요.

전에는: 교재를 바꾸어도 이전 교재의 답 입력창이 남아 있었어요.
지금은: 이전 회차를 닫고 새로 고른 교재의 회차를 선택하도록 했어요.
확인법: 3권 회차를 열었다가 4권을 눌러 보세요.

정한 것
- 불러오기 전에 기기에 보관한 답을 바꿀지 확인해요. 읽지 못한 답도 확인 없이 지우지 않아요.
- 입력 뒤 바로 저장해도 방금 입력한 답까지 포함해요.
- 유료 인공지능은 쓰지 않아요. 최신 답 불러오기는 버튼을 눌렀을 때만 요청해요.
- 전체 검토를 마친 준비본이에요. 운영 반영은 8차에 진행해요.
