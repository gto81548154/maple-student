# 토익 답 입력과 자동채점

전에는: 맞은 개수를 직접 적어야 했어요.
지금은: 회차별로 답을 넣고 채점하면 맞은 개수와 파트별 결과, 틀린 답을 볼 수 있어요.
확인법: 토익 → 회차 선택 → 답 입력 → 채점하기를 눌러 주세요.

전에는: 회차 전체의 입력 답을 따로 보관할 수 없었어요.
지금은: 답은 이 기기에 먼저 남고, 답 저장을 누르면 다른 기기에서도 이어 풀 수 있어요. 연결이 끊기면 저장 대기 상태를 보여 줘요.
확인법: 몇 개를 입력하고 화면을 다시 열어 본 뒤, 답 저장을 눌러 저장 상태를 확인해 주세요.

전에는: 직접 채점한 숫자만 볼 수 있었어요.
지금은: 빈칸은 확인을 받은 뒤 오답으로 처리하고, 답을 바꾸면 이전 결과임을 알려 줘요.
확인법: 답을 덜 넣은 상태로 채점하기를 누르고, 채점한 뒤 답 하나를 바꿔 보세요.

정한 것
- 정답과 입력한 답을 비교하므로 유료 인공지능을 사용하지 않아요.
- 답을 고를 때마다 서버에 보내지 않아요. 답 저장·채점하기를 눌렀을 때 전송해요.
- 연결 오류 때 계속 반복 호출하지 않아요. 다시 저장을 누르거나 연결이 돌아오면 재시도해요.
- 결과는 100개 중 맞은 개수이며 공식 토익 환산 점수가 아니에요.
- 아직 배포하지 않았어요. 전체 검토는 7차, 운영 반영은 8차예요.
