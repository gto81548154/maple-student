## A. 마플보카(`public/voca.html`) 객관식 채점 색
지금: 채점 뒤 정답 보기는 초록(`.mcop.right` + "정답" 표시), 내가 고른 오답은 빨강 계열 글자 "내 선택"(`.mcop.wrongpick` + `.mark.no`)인데 원장 눈에는 파란색으로 보인다고 함. 고치는 함수는 `mcGrade`쯤(검색: `'<span class="mark no">내 선택</span>'`).

바꿀 것:
1. **내가 고른 오답 보기** = 바탕·테두리·"내 선택" 글자 모두 **빨강** 계열(#D2402E / 연한 바탕 #FDECEA).
2. **정답 보기** = **파랑** 계열(#2A6FDB / 연한 바탕 #E8F0FF). "정답" 글자도 파랑.
3. **지난번에 이 단어에서 내가 골랐던 오답 보기** = **노랑** 계열(#F2C14E 테두리 / 연한 바탕 #FFF6D5) + 작은 글자 "지난번 오답". 이번에 또 그걸 골랐으면 1번(빨강)이 우선.
   - 저장: 단어별 기록(`W(w.id)`로 받는 p 객체)에 `wp`(wrong picks) 배열을 두고, 오답으로 고른 보기의 **뜻 글자**를 넣는다(최대 5개, 중복 없음). 기존 저장 방식(로컬 저장·서버 동기화)이 p를 통째로 저장하면 그대로 따라간다.
   - 표시: 보기를 그릴 때(`mcList`를 만들어 `#mcOps`에 넣는 곳) 그 단어의 `wp`에 있는 뜻이면 채점 **전**부터 노란 테두리로 보여 준다(힌트 역할). 채점 뒤에도 노란색 유지(정답/내 선택이 아니면).
4. 색은 CSS 변수로 두고(`--mc-wrong`, `--mc-right`, `--mc-prev`), 다크 모드(`html.bh`)에서도 글자가 보이게 어두운 바탕용 값을 따로 둔다.

## B. 오답 복습(`src/screens/vocab/VocabWrongTab.jsx`) 채점이 너무 엄격한 것
지금: 학생이 적은 뜻을 `norm()`으로 다듬은 뒤 정답 목록(`buildVocabAcceptList`)과 **완전히 같아야** 정답. "비정상의"라고 적었는데 정답이 "비정상적인"이라 오답 처리됨.

바꿀 것(`src/domain/vocabAnswer.jsx`에 `isVocabAnswerClose(input, accept)` 같은 함수를 만들어 VocabWrongTab에서 쓴다):
1. 완전히 같으면 정답(지금 그대로).
2. 그다음 **어미를 떼고** 비교한다: 양쪽 끝에서 `의, 적인, 적, 한, 하는, 하다, 되다, 되는, 된, 스러운, 스럽다, 로운, 롭다, 이다, 다, 인, 는, 을, 를` 중 하나를 떼고(한 번만), 띄어쓰기·"~"·"-"·괄호는 지우고 같으면 정답. 예: 비정상의 ↔ 비정상적인 ✔, 행복한 ↔ 행복하다 ✔, 설명하다 ↔ 설명 ✔.
3. 그래도 다르면: 둘 중 하나가 다른 하나의 **앞부분**이고 남은 부분이 2번 어미 목록에 들어가면 정답.
4. 위 규칙으로 맞은 경우는 결과 화면에 "정답 (비슷한 표현: 비정상적인)"처럼 정답 표기도 같이 보여 준다.
5. 여기서 만든 함수는 마플보카(voca.html)의 뜻 쓰기 채점에는 **아직 안 붙인다**(이번엔 오답 복습만).
