# 학생앱 143차수 검토 — 마플보카 객관식 색 + 오답 복습 채점 기준 (2026-11-03)

바뀐 것마다 "전에는 / 지금은 / 확인법" 세 줄로 적었습니다.

## A. 마플보카 객관식 채점 색

### 1. 내가 고른 오답 보기는 빨강
- 전에는: 틀린 보기에 "내 선택"이 붙는데, 학생앱 안에서는 그 색이 파란색으로 보였어요(학생앱 디자인이 빨강 자리를 파랑으로 바꿔 쓰고 있어서).
- 지금은: 바탕·테두리·"내 선택" 글자 모두 빨강 계열이에요. 학생앱 안에서도, 따로 열어도, 어두운 모드에서도 빨강이에요.
- 확인법: 단어 탭에서 객관식 문제를 하나 틀려 보세요. 내가 누른 보기가 빨갛게 돼요.

### 2. 정답 보기는 파랑
- 전에는: 정답 보기와 "정답" 글자가 초록이었어요.
- 지금은: 파랑 계열 바탕·테두리에 "정답" 글자도 파랑이에요.
- 확인법: 객관식을 풀면 정답 보기가 파랗게 돼요.

### 3. 지난번에 골랐던 오답 보기는 노랑 + "지난번 오답"
- 전에는: 전에 뭘 틀렸는지 보기에서는 알 수 없었어요.
- 지금은: 어떤 단어에서 오답을 고르면 그 보기의 뜻을 단어별 기록에 남겨 둬요(최대 5개, 같은 건 한 번만, 오래된 것부터 밀려남). 다음에 같은 단어가 나오면 그 보기는 채점 전부터 노란 테두리에 "지난번 오답" 글자가 붙어 힌트가 돼요. 채점 뒤에도 노란색은 그대로예요. 이번에 또 그 보기를 고르면 빨강(내 선택)이 이겨요. 기록은 원래 저장되던 곳에 같이 저장·동기화돼요.
- 확인법: 어떤 단어를 일부러 틀린 뒤, 나중에 같은 단어가 다시 나올 때 보기 색을 보세요.

### 4. 어두운 모드(블랙홀)에서도 글자가 보임
- 전에는: 해당 없음(새 색).
- 지금은: 어두운 바탕용으로 빨강·파랑·노랑을 조금 밝게 따로 두어 글자가 잘 보여요.
- 확인법: 마플보카 블랙홀 모드에서 객관식을 풀어 보세요.

## B. 오답 복습 채점이 너무 엄격한 것

### 5. 어미가 달라도 정답으로 인정
- 전에는: 학생이 적은 뜻이 정답과 완전히 같아야만 정답이었어요. "비정상의"라고 적었는데 정답이 "비정상적인"이면 오답이었어요.
- 지금은: 순서대로 봐요. ① 완전히 같으면 정답. ② 양쪽 끝에서 어미(의·적인·적·한·하는·하다·되다·되는·된·스러운·스럽다·로운·롭다·이다·다·인·는·을·를) 중 하나를 한 번 떼고, 띄어쓰기·물결·줄표·괄호를 지운 뒤 같으면 정답. ③ 그래도 다르면 한쪽이 다른 쪽의 앞부분이고 남은 글자가 위 어미 중 하나면 정답.
- 확인법: 더보기 > 오답 복습에서 정답이 "비정상적인"인 단어에 "비정상의"라고 적어 보세요.

### 6. 비슷한 표현으로 맞으면 정답 표기도 같이 보여 줌
- 전에는: "정답입니다!"만 떴어요.
- 지금은: ②·③으로 맞은 경우 "정답입니다! (비슷한 표현: 비정상적인)"처럼 어떤 정답과 통한 건지 같이 보여요. 완전히 같을 때는 전처럼 "정답입니다!"만 떠요.
- 확인법: 위 5번처럼 적어 보면 제목 옆에 괄호 글이 붙어요.

### 비교 규칙 예 8개

| 입력 | 정답 | 결과 |
|---|---|---|
| 비정상의 | 비정상적인 | 정답 (비슷한 표현: 비정상적인) |
| 행복한 | 행복하다 | 정답 (비슷한 표현: 행복하다) |
| 설명하다 | 설명 | 정답 (비슷한 표현: 설명) |
| 비정상적이다 | 비정상적 | 정답 (비슷한 표현: 비정상적) |
| 사랑스러운 | 사랑스럽다 | 정답 (비슷한 표현: 사랑스럽다) |
| 주소 | [명] 1. 주소 2. 연설 [동] 1. 주소를 쓰다 | 정답 (완전히 같음 — 낱개 뜻 "주소") |
| 행복 | 행복하게 | 오답 ("하게"는 어미 목록에 없음) |
| 생각 | 생각하지 않다 | 오답 |

(위 8개는 실제로 돌려 본 결과예요.)

### 7. 마플보카의 뜻 쓰기 채점은 그대로
- 전에는/지금은: 마플보카(단어 탭) 안의 뜻 쓰기 채점은 이번에 손대지 않았어요. 새 규칙은 오답 복습에만 붙었어요.
- 확인법: 단어 탭 뜻 쓰기는 전과 똑같이 채점돼요.
